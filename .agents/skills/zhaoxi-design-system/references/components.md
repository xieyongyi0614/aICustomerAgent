### A2. ai-card（AI 结论卡）★ 全站视觉焦点

```
背景 surface · 圆角 rLg · 内边距 18 · 投影 shadowCard
渐变描边：1.5px，用 ai 渐变，不透明度 .55
```

**描边实现**：CSS 用 `padding:1.5px` + `mask-composite: exclude`。Flutter **不支持** `Container.border` 渐变，须自绘（见 `flutter-mapping.md` §3）。

**结构**：

```
[✦ 图标 13px] 今日 AI 总结          ← 标签：12px/700，字距 .06em，色 aiPrimary
<正文 14.5px/1.75，色 bodyOnCard>
[查看完整早间简报 →]                ← 13px/600，色 aiBlue
```

> **纪律**：渐变描边**只属于本组件**。普通卡片加渐变描边 = 违反红线 1。

### A14. proc（工具调用过程卡）★ 核心差异化

```

      执行中 → 旋转圈 15px（0.9s）｜已完成 → 绿色对勾 13px
步骤行：内边距 8/0 · 底部虚线 1px line（末行无）· 13.5px
        图标位 20px 圆 · 步骤名 600 · 右侧明细 12px 色 ink3 右对齐
```

**步骤三态（这是本组件的灵魂）**：

| 态 | 图标表现 | 步骤名颜色 |
|---|---|---|
| `done` | 底 `rgba(51,188,140,.14)`，绿色对勾 | 正常 |
| `running` | 2px 环，色 `rgba(122,92,255,.25)`，**顶边为 aiPrimary**，0.9s 旋转 | 正常 |
| `todo` | 1.6px 边框 `#DDDCD4`，无内容 | **ink3（灰显）** |

**明细列必须写「结果落点」**，例如：`¥35.00` / `餐饮 · 午餐` / `今天 12:32` / `已同步到「生活 · 记账」`。

## B. 页面结构（9 页）

信息流**严格**：先结论 → 后数据 → 再行动。

```

               [模式 chip]「Default 模式 · 长期记忆运行中」
3. AI 结论卡   [✦]「今日 AI 总结」+ 跨域合成正文 + 「查看完整早间简报 →」

5. 指标三宫格  睡眠 7h12m（优于上周）／静息心率 62bpm（平稳）／步数 6,234（目标 8,000）
6. 区块标题    「今日任务」+ hint「3 项 · AI 已排序」
7. 任务列表    回复导师邮件（已完成）／15:00 产品方案对齐（14:30 提醒）／给妈妈回电话（晚间）
```
