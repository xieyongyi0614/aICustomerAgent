### A2. ai-card（AI 结论卡）★ 全站视觉焦点

```
背景 surface · 圆角 rLg · 内边距 18 · 投影 shadowCard
渐变描边：1.5px，用 ai 渐变，不透明度 .55
动作行（可选，1~2 枚）：上边距 13 · 间距 9
              [主 chip] 底 aiPrimary 9% + aiPrimary 20% 描边 + 字 12.5px/600 aiPrimary
              [次 chip] ghost 变体：底 surface + line 描边 + 字 ink2
```

**描边实现**：CSS 用 `padding:1.5px` + `mask-composite: exclude`。Flutter **不支持** `Container.border` 渐变，须自绘（见 `flutter-mapping.md` §3）。

**结构**：

```
[✦ 图标 13px] 今日 AI 总结          ← 标签：12px/700，字距 .06em，色 aiPrimary
<正文 14.5px/1.75，色 bodyOnCard>
[查看完整早间简报 →]                ← 13px/600，色 aiBlue
```

> **纪律**：渐变描边**只属于本组件**。普通卡片加渐变描边 = 违反红线 1。

### A9. tabbar + orb-btn（底部导航）★ 必须自绘

```
Tab 栏：高 88，底 rgba(255,255,255,.92) + 18px 背景模糊，上边线 1px line
5 个位置：首页 / 动态（可变槽，默认「记账」）/ 对话（悬浮球）/ 生活 / 我的
Tab 文字 10.5px/600，图标 23px，未选色 ink3，选中色 ink
对话位：flex 0 0 76（5 位里的第 3 位；左右各 2 位等分 → **正好整栏居中 50%**）
动态位：位置恒在第 2 位，文案与图标随设定模块变化（默认「记账」+ 钱包图标）
悬浮球：56px 圆，ai 渐变底，阴影 orbBtnShadow（外圈 6px 与页面底色同色、辉光压在圈上）
       `.orb-btn{top:-24px}` 相对 `.orb-tab` 项算，而该项已在栏顶内边距 12 之下
       → **相对栏顶 = 12 - 24 = -12**；内为白色 ✦ 四芒星 24px
对话文字：`.orb-tab span{margin-top:36px}` 同样相对 `.orb-tab` 项算
       → **相对栏顶 = 12 + 36 = 48**（比其余 Tab 的文字低 10，贴在球的挖空圈下沿）
```

> ⚠️ 两个 `-24` / `36` 都是相对 `.orb-tab` 项而非栏顶写的，按栏顶取值会让球与「对话」整体偏高 12px。

**规则**：Tab 栏出现在首页 / 生活 / 我的 / 健康页，以及**动态位的模块根页**（动态位渲染的 6 个模块页 —— 记账 31 / 备忘录 41 / 日程 42 / 健康 32 / 车辆 35 / 相册 37 —— 作为 Tab 根时显示 Tab 栏，且**不得出现「‹ 生活」返回**）；同一模块从生活宫格进入时是二级页形态（**Tab 栏隐藏 + 「‹ 生活」返回**）。进入记一笔 / 简报页 / 相册二级页等子流程页时 **Tab 栏隐藏**；简报页状态栏文字转白色。**记忆不是主 Tab**（2026-09-30 / 2026-10-03 IA 裁决：记忆降级为「我的 · 记忆管理」子页）。

### A14. proc（工具调用过程卡）★ 核心差异化

```

左边距 31（与 AI 气泡对齐）· 最大宽 86% · 下边距 14

      执行中 → 旋转圈 15px（0.9s）｜已完成 → 绿色对勾 13px

        图标位 20px 圆 · 步骤名 600 · 右侧明细 12px 色 ink3 右对齐
```

**步骤三态（这是本组件的灵魂）**：

| 态 | 图标表现 | 步骤名颜色 |
|---|---|---|
| `done` | 底 `rgba(51,188,140,.14)`，绿色对勾 | 正常 |
| `running` | 2px 环，色 `rgba(122,92,255,.25)`，**顶边为 aiPrimary**，0.9s 旋转 | 正常 |
| `todo` | 1.6px 边框 `#DDDCD4`，无内容 | **ink3（灰显）** |

**明细列必须写「结果落点」**，例如：`¥35.00` / `餐饮 · 午餐` / `今天 12:32` / `已同步到「生活 · 记账」`。
