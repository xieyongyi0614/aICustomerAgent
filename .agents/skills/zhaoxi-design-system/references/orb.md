# AI 核心球（The Orb）规格

> Orb 是朝夕的**本体视觉** —— 全站唯一承载「AI 的存在」的元素。设计稿 §04+ 裁决采用**方案 A：抽象光球**。
> 优势（设计稿原话）：抽象不占空间、与「未来感 + 温暖」契合、动画成本低、可承载全部状态语义。**SAO 式的 10% 科技感全部倾注在这里。**

---

## 1. ⚠️ 先分清两个「球」

原型里有两个圆形视觉，**不是同一个东西**，容易混：

| | Orb（AI 本体） | 悬浮对话球（入口按钮） |
|---|---|---|
| 视觉 | **径向渐变** + 内层旋转高光 | **线性渐变** `ai` + 白色 ✦ 图标 |
| 动效 | 呼吸 + 色相流动 | 无 |
| 尺寸 | 76 / 34 / 22 | 56 |
| 位置 | 首页 Hero、对话头像、健康 Hero、人格卡、简报页 | 底部 Tab 栏中间（上浮 24px） |
| 用途 | 表达 AI 状态 | 表达「点这里说话」 |

**禁止**把 Orb 放进 Tab 栏，也禁止给悬浮球加呼吸动效（它是个按钮，不是生命体）。

## 2. 待机态视觉规格（原型已实现，可直接照做）

### 2.1 底层

```
圆形 · 径向渐变（圆心 32% 28%）
  0%   → #D9CCFF   （左上高光）
  34%  → #8B6DFF   （AI 紫主体）
  66%  → #4D6BFF   （AI 蓝）
  100% → #1FB9D8   （AI 青边缘）

内描边：inset 0 0 0 1px rgba(255,255,255,.5)
外发光：0 10px 30px rgba(102,90,255,.45)
        0 0 60px rgba(63,150,255,.35)
```

### 2.2 内层（叠加层，`::after` 等价物）

```
两层径向渐变，叠加模式 = screen（屏幕）
  A: 圆心 68% 72%，rgba(43,210,232,.85) → transparent 46%
  B: 圆心 30% 26%，rgba(255,255,255,.90) → transparent 30%

整体以 7s 线性无限旋转（rotate 0 → 360deg）
```

### 2.3 呼吸

```
4.2s ease-in-out 无限循环
scale 1 → 1.055 → 1
```

> 定稿值 **4.2s**。设计稿 §04+ 写的 4s 不采用。

### 2.4 登录欢迎页 Hero 晕盘（`lg-orb-wrap::after`）

登录页大球外圈的**静态**紫色辉光盘，属于页面组合（只有登录欢迎页用），不是 Orb 的状态：

```
直径 = 160px（lg 76 球的 2.105 倍），以球心为中心，溢出绘制不占布局
径向渐变：rgba(122,92,255,.20) → transparent（68% farthest-corner ≈ 球半径 2.02 倍处消失）
无动效（不呼吸、不旋转）；晕盘在球体之下层
```

Flutter 实现：`ZhaoxiOrb(size: lg, halo: true)`（`design/flutter/zhaoxi_orb.dart`）。外层容器**不要裁剪**（不要用 ClipRect 包裹，晕盘靠溢出绘制）。

## 4. 四态语义

设计稿 §04+ 定义四态，**原型只实现了「待机」**。以下为落地规格，**标「推导」的部分是依据设计稿文字补全的实现约定**，实现后可回写本节。

| 态 | 语义 | 配色 | 动效 | 触发场景 |
|---|---|---|---|---|
| **待机 / 陪伴** | 安静存在 | 蓝紫（§2 规格） | 呼吸 4.2s + swirl 7s | 首页 Hero、对话头像（默认） |
| **思考 / 执行** | 正在为你做事 | 蓝紫 + conic 色相流动 | 呼吸幅度加大至 1.08；swirl **加速至 2.4s**；叠加 conic 渐变旋转 | 工具调用进行中（配合 `proc` 过程卡） |
| **主动关怀** | 我要跟你说件事 | 暖橙 | 非对称脉冲 1.8s（快起慢落） | 早间简报、异常提醒 |
| **完成 / 成长** | 做完了 / 长大了 | 青绿 | 一次性绽放：scale 1 → 1.18 → 1，600ms，**只播一次** | 任务完成、记忆新增、关系升级 |

**推导配色**（设计稿只给了色相词，未给具体值）：

| 态 | 径向渐变（圆心 32% 28%） |
|---|---|
| 主动关怀 | `#FFE6D2 0% → #FFB48F 36% → #FF9D76 68% → #FF7A4D 100%` |
| 完成 / 成长 | `#C8F7E4 0% → #6FD9B4 36% → #33BC8C 68% → #1F9A70 100%` |

> **纪律**：完成态播完必须**回到待机**，不能停在青绿（否则「AI 永远在庆祝」）。
> **纪律**：同一时刻只有一态。多态冲突时优先级：`完成 > 主动关怀 > 思考 > 待机`。

## 5. 渲染实现要求

### 5.1 分层

```
Orb(size, state)
 └── RepaintBoundary                    ← 隔离重绘
     └── CustomPaint(painter: OrbPainter)
         ├── controller Breathe  (4.2s, repeat reverse)   ← 常驻
         └── controller Swirl    (7s, repeat)             ← 仅待机/思考启用
```

### 5.2 关键技术点

| 点 | 做法 |
|---|---|
| 底层径向渐变 | `RadialGradient(center: Alignment(-0.36, -0.44))` 对应 CSS 的 `32% 28%` |
| **CSS farthest-corner 换算** | CSS `radial-gradient` 默认半径 = 圆心到**最远角**，Flutter `radius` 是**短边分数**（无 farthest-corner 语义，默认 0.5）。76px 球换算：底层 1.0、青光 **0.99**（0.46 × 75.2px）、白光 **1.02**（0.30 × 77.4px）；照抄 CSS 百分比当 radius 会让高光缩小 30–50% |
| 内层高光叠加 | `Canvas.saveLayer(bounds, Paint())` → 画底层 → 第二层起用 `Paint()..blendMode = BlendMode.screen` → `restore()` |
| 旋转 | 对整个内层做 `canvas.rotate(angle)`，**不要逐帧重算渐变坐标** |
| 呼吸 | 用 `Transform.scale` 包外层，**不要重绘 painter**（painter 只依赖状态，不依赖呼吸进度） |
| 内描边 | `Paint()..style = PaintingStyle.stroke..strokeWidth = 1` 画 1px 白圈，**α 0.5**（高光用的 innerWhite 本体 α0.9，描边需 withValues 降回） |
| **外发光（box-shadow 换算）** | CSS `0 10px 30px rgba(102,90,255,.45)` + `0 0 60px rgba(63,150,255,.35)` → 球后两层 `MaskFilter.blur(BlurStyle.normal, σ)` 圆：紫层 center+(0,10) σ15、蓝层 center σ30（**blur-radius ≈ 2σ**），先画蓝层、紫层（首列）盖上。**必须画在 saveLayer 之外**——辉光溢出球体方框，进 saveLayer 会被边界裁掉；外层容器也不可裁剪（Stack 需 `clipBehavior: Clip.none`） |
| flutter_hooks 订阅 | `useAnimationController` 不触发重建，必须 `useListenable(controller)` 订阅 tick，否则动画静止 |

> ⚠️ `saveLayer` 开销大。**必须**包 `RepaintBoundary`，且只在 Orb 可见时开动画。

### 5.3 性能与功耗（移动端硬要求）

| 措施 | 原因 |
|---|---|
| `RepaintBoundary` 包裹 | 隔离重绘，不带动整页 |
| `TickerMode` 感知 | 页面不可见 / App 进后台时**必须停表**，否则纯耗电 |
| 首页长列表滚动时降频或暂停 | Orb 在首屏顶部，滚动时可暂停 |
| painter 内缓存 `Path` / `Shader` | 禁止逐帧重建 |

### 5.4 无障碍

```dart
Semantics(label: '亚丝娜，AI 助手', child: ...)
```

## 7. AI 语义符号：✦ 四芒星

Orb 之外，**AI 的「行动痕迹」统一用四芒星标记**（不是 Orb）：

```
M12 2l2.4 7.2L22 12l-7.6 2.8L12 22l-2.4-7.2L2 12l7.6-2.8z
```

出现位置：AI 结论卡标题、记忆提示条、模式 chip、工具过程卡头部、悬浮对话球、快速捕获条、加载占位。

颜色：常规 `aiPrimary`；悬浮球内为白色。
