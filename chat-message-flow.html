四、前台九段逐段详解

4.1 第 2 段 · context_assembly

装配「角色当下看到的世界」，并选出本轮目标。

4.2 第 3 段 · turn_decisions

四条链并行推理，任一失败只降级该项。

4.3 第 4 段 · mode_stabilize

抑制模式抖动，产出本轮生效的角色模式。

4.4 第 5 段 · scene_resolve

4.5 第 6 段 · behavior_resolve

4.6 第 7 段 · action_planning

检出行动意图，并发出首帧 turn_meta。

4.7 第 8 段 · reply_generation

唯一关键段：流式生成回答并做库存 grounding。

4.8 第 9 段 · record_handoff

落库、调度后台、发出结束帧。

七、各环节作用

环节作用
入口层把 HTTP 请求翻译成一次「对话 Run」的输入，保证鉴权 / 校验 / 追踪 id；用流式响应换取首字延迟
context_assembly装配「角色当下看到的世界」——AgentState 快照、世界上下文、会话状态、场景、本轮目标
turn_decisions四链并行产出本轮的角色模式 / 情绪分析 / 场景意图 / 意图决策，单链失败即降级
mode_stabilize抑制模式抖动，防止一句话就来回切换角色语气
scene_resolve收敛场景 + 校验意图 + 跑前台决策管线（目标栈只读）
behavior_resolve决定「怎么回应」——关系上下文、行为策略、风格契约
action_planning检出行动意图并发出首帧 turn_meta
reply_generation唯一关键段：逐 token 流式回答 + 库存 grounding 重写；失败必须冒泡
record_handoff落库、复位主动行为、调度后台、发出 done
