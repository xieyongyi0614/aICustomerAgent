## 拆分规则

- 编号十位 = 信息架构分组（0 登录 / 1 首页 / 2 对话 / 3 生活 / 4 记忆·生活扩展 / 5 我的 / 6 相册扩展）；`39` 沿用生活段空号，`41 / 42` 为生活段溢出编号（备忘录 / 日程）。
- 页面内按钮、返回键、底部 Tab 的跳转链接已由 `#hash` 改写为文件互跳，跳转关系与拆分前的原型一致（Tab 栏为 5 个主 Tab：首页 / 动态 / 对话 / 生活 / 我的，其中第 2 位「动态」是可变槽、原型统一按默认态「记账」绘制；Tab 栏仅出现在首页 / 生活 / 我的与健康页；33–42 为子流程页，不带 Tab 栏；记忆自 2026-09-30 起降级为「我的」子页）。
- 每页文件自带全部所需样式（含手机壳、状态栏、AI Orb），单文件零依赖。
- 页面右下角的「页面直达」演示导航与页脚总览 / 设计说明链接为拆分版新增，便于评审跳转；页脚的「连续原型」指向冻结存档，仅供对照（33–38 为新增页面，无冻结锚点）。
- 设计规范与组件规格的唯一真源是 `.agents/skills/zhaoxi-design-system/`（优先级高于本目录一切文件）。
- `ai-life-agent-design.html` 保持原样，其首页按钮与页脚仍指向冻结原型，未随本次拆分改动。

## 2026-09-30 信息架构调整（生活 / 记账 / 记忆）

- **生活宫格收敛为 6 格**：记账 / 备忘录（41，新增页）/ 日程（42，新增页）/ 健康 / 车辆 / 相册。原「任务」「日历」合并为**日程**（同属时间安排）；「旅行」不再单列模块，作为场景出现在日程「即将到来」与对话（旅行规划 Tool Call）中。原则：宫格不允许出现没有对应页面的悬空入口。
- **记账合并为单一模块**：手动与 AI 对话录入是同一「记一笔」（33）的两种方式（说给亚丝娜 / 键盘输入同页切换），不再拆「手动记账 / AI 自动记账」两个并列模块；原 34 的「待确认账单」并入账本首页（31），34 改为二级页「同步与 AI 规则」（同步来源 + AI 学会的规则）。
- **记忆降级**：从底部 Tab 移除（Tab 变 4 个：首页 / 生活 / 对话 / 我的），40 记忆页保留为「我的 · 记忆管理」的子页；记忆是低频透明度功能，透明度诉求由「我的」与对话内记忆提示条承接。

## 2026-09-30 新增模块说明

- **记账扩展（33 / 34）**：手动记账走金额键盘 + 分类宫格，备注交由 AI 匹配分类；AI 自动记账承接账单同步（微信 / 支付宝 / 银行卡短信 / 语音），AI 拿不准的账单进入「待确认」，用户修正会沉淀为「AI 学会的规则」。
- **车辆（35 / 36）**：电车向设计——车贷还款进度、充电费 / 电耗 / 里程、养车支出分类、保养 / 车险 / 限行提醒；养车记一笔与记账域打通（费用自动计入「生活 · 记账」养车分类）。
- **相册（37 / 38）**：**仅本地管理，不上传服务器**——分类相簿在本机自动归类，AI 整理建议（截图 / 相似照片清理）全程本机分析；批量管理支持多选、移动相簿、批量加标签、批量删除（「最近删除」保留 30 天）。

## 2026-09-30 车辆 / 相册闭环补全（39 / 60 / 61 / 62）

- **车辆档案（39）**：车辆主页新增「车辆档案」入口（仅入口卡片为新增，35 / 36 其余版式未动）——车型 / 车牌 / 电池容量 / 车龄 / 里程，保险、年检、家用充电桩、保养周期四条档案行，保养记录时间线（含「下一次保养」未发生态），末行常驻「保养费用同时计入记账养车分类」的联动口径。
- **AI 整理建议详情（62）**：相册主页的 AI 建议卡改为先进本页（原先直跳批量管理）——三类建议（过期截图 / 相似连拍 / 重复保存）各带数量与体积并可点进批量管理，另有四条「我的整理原则」（只在本机算、只预选不自动删、30 天可恢复、推翻会被记住）。
- **相簿详情（60）**：相册主页「旅行」相簿点入——按拍摄日期分组的照片墙，视频带时长徽章，AI 留下的连拍原片标 ✦，页内保留仅本机口径。
- **单张照片（61）**：照片墙点入——大图 + 「我留了这张」✦ 徽章 + AI 说明（同场景另外 3 张建议清理，可一键去对比），照片信息行（时间 / 地点 / 相簿 / 大小，逐项标注本机读取或归类），底部固定操作栏（收藏 / 移到相簿 / 删除）与「仅本机 · 最近删除 30 天」常驻口径。
- **跳转关系**：`35 → 39 → 36`；`37 → 62 → 38`、`37 → 60 → 61 →（对比）38`；38 的 AI 提示条下方新增「这些预选是怎么算出来的 →」回指 62。
