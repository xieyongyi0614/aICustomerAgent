# V4 真实模型人工回归清单

> FakeLLM 只能验证管线与状态机逻辑，提取器判定质量必须以真实 LLM 回归为准。执行：启动后端 + 前端，逐场景重放并核对断言。

## 1. 跨会话偏好记忆（对应 testing.md 十项必测之外的语义质量验证）

| 轮 | 会话 | 用户输入 | 核对 |
|---|---|---|---|
| 1 | 会话 A | 我从来不喝咖啡，只喝茶 | Debug 记忆列表新增 user_preference「用户不喝咖啡」，source=user_stated |
| 2 | 会话 B（新会话） | 给我推荐个喝的 | 回复自然体现「茶」，不推荐咖啡 |
| 3 | 会话 B | 你还记得我喜欢什么吗 | 自然回答喝茶/不喝咖啡，不罗列记忆原文 |

## 2. 冲突更新

| 轮 | 会话 | 用户输入 | 核对 |
|---|---|---|---|
| 1 | 会话 A | 我每天都喝咖啡 | 保存「用户喝咖啡」 |
| 2 | 会话 B | 我现在戒咖啡了，改喝花茶 | 旧行 superseded/invalidated，仅一条 active；后续不再提咖啡 |

## 3. 隐私指令

| 轮 | 会话 | 用户输入 | 核对 |
|---|---|---|---|
| 1 | 会话 A | （说一件个人事实） | 正常保存 |
| 2 | 会话 A | 这件事别记了，忘了吧 | 对应行被硬删除（Debug 列表消失）；本轮其他内容不被保存（suppress 生效） |

## 4. 表达层约束

- 任意多轮闲聊后：回复不主动罗列记忆（「你知道你喜欢西瓜、你养猫……」式念叨禁止）。
- 记忆仅在与话题自然相关时出现。
- 闲聊刷屏 10+ 轮：Debug 记忆列表无膨胀（单轮 ≤3 条硬上界生效）。

## 通过判定

- 上述场景全部命中；提取归类明显错误（如闲聊入库、推测入库）记录并反馈到 extractor prompt 迭代。
- 全量 `uv run pytest tests/ -v` 保持全绿。
