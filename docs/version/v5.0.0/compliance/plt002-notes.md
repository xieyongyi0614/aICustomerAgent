## 新增调研结论（2026-10-08，接上表编号）

| # | 事项 | 结论 |
|---|---|---|
| 5 | **软著费用口径** | **官方登记 0 元**：财政部财税〔2017〕20 号取消「软件著作权登记费」，中国版权保护中心自 2017-04-01 停征（含登记申请费、登记证书费等 6 类项目）；市面「300 元」实为代办费 / 加急费 / 第三方《APP 电子版权证书》价 |
| 6 | **vivo 个人开发者通道** | 2026-09-16 vivo 开发者大会宣布应用商店开放个人开发者通道（实名即可，「有序开放 AI 应用 / 蓝河 / IoT」）；⬜ 类目开放范围、是否接受电子版权证书、AI 材料形式待工单核实（见上架指南 §3.1） |
| 7 | **软著与 App 备案的关系** | 工信部备案申报材料**未列软著**；软著是**商店准入**硬门槛（vivo 三选一强制、一证一应用、名称须一致）；备案实操中接入商常要求权属材料 |
| 8 | **AI 类：备案 vs 登记** | 只调用已备案第三方大模型 API 且不改动底层模型 → 行业口径一般按「大模型登记」办理；自研 / 深度微调 → 完整大模型备案（1–6 个月，个人主体难度高）。**未备案一律不予上架** |
| 9 | **自分发的合规边界** | 自分发不需要软著、不经商店备案核验；但生成式 AI、AI 内容标识、隐私义务**不豁免**；公开推广或收费会显著抬高风险等级（详见 `self-distribution-guide.md` §6 / §8） |
