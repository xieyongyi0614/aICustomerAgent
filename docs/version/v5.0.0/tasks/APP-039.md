## 3. Scope

### 3.1 In Scope

1. `album_ai_page.dart`：照 B17 的 9 段。
2. 路由 `/album/ai`（`chromeImmersive`）。
3. **建议行**：`SuggestionRow`（A38）× 已实现类别数（过期截图 / 重复保存各一行），每行含类型 + 判定理由 + 张数 + 体积，整行可点 → `/album/manage`。
4. **相似连拍**：独立一行呈**诚实未支持态**（说明本期不做、无张数、无体积、不可点）。
5. **合计口径**：AI 结论卡的「共 N 张 / 共 X GB」= **已实现类别之和**（不含连拍）。
6. 「我的整理原则」四条（文案沿用 `pages/62:136-139`，逐条对齐真实能力：第 4 条对应 `album_local_store` 的推翻记录）。
7. CTA → `/album/manage`。
8. 隐私卡：口径同 `APP-035` / `APP-037`（**不含「不需要联网权限」**，含「无云同步」「随时可以停下」）。
9. 零网络。

### 3.2 Out of Scope

| # | 不做 | 理由 |
|---|---|---|
| 1 | **相似连拍建议行给出张数与体积** | D16；给数即造假（`APP-014` 红线） |
| 2 | 原则条的**可编辑**（用户改整理原则） | 设计稿四条为陈述（`pages/62:134-140`），无编辑交互 |
| 3 | 未分类相簿的归类动作 | 归 `APP-035` §3.2 #2（本期只读） |
| 4 | 建议的定时重扫 / 后台扫描 | 无设计要求；后台扫描会引入功耗与权限议题 |
| 5 | 大数据集导出报告 | 反范围（会产生文件路径与外发可能） |
| 6 | 端上重算分析 | 归 `APP-034` |

## 4. Technical Design Requirements

### 4.1 页面契约（照 `components.md:683-699` B17）

| # | 段 | 组件 | 内容 |
|---|---|---|---|
| 1 | 返回 | `BackLink` | 「‹ 相册」 |
| 2 | 标题 | 页标题 + 副题 | 「整理建议」+「在你这台手机上扫完 N 张 · 本机分析」 |
| 3 | AI 结论卡 | `AiCard` | 已实现类别合计 + **承诺句**「我先替你预选好，删之前由你确认——我不会自己动手」 |
| 4 | 区块标题 | `_SectionTitle` | 「可清理的 N 张」+ hint「合计 X」 |
| 5 | 建议行（已实现） | **`SuggestionRow`（A38）** × N | 图标方块 42px / 圆角 14；标题 14.5px/600；**理由 11.5px `ink3`（必填）**；右侧双行（张数 14.5px/700 / 体积 11px `ink3`，`tabular-nums`）；整行可点 → `/album/manage` |
| 6 | 建议行（未支持） | 同型但非可点 | 「相似连拍」+ 未支持说明，**无张数 / 无体积** |
| 7 | 区块标题 | `_SectionTitle` | 「我的整理原则」+ hint「一直这样」 |
| 8 | 原则卡 | 列表卡 | 四条（只在本机算 / 只预选不自动删 / 删错了也能回来 30 天 / 你的推翻我会记住） |
| 9 | CTA + 隐私卡 | 主按钮 + `PrivacyNote` | 「看看这 N 张，已帮你预选」→ `/album/manage`；隐私卡按 §3.1 #8 |

### 4.2 关键裁决

| # | 裁决 | 理由 |
|---|---|---|
| 1 | **相似连拍独立成行但呈未支持态，且不计入合计** | D16；若混入合计，AI 结论卡的「共 76 张」即假结论 |
| 2 | **每行判定理由必填** | `components.md:396` 纪律「不能只给类型名与数量」；理由文案须与 `APP-034` 的实际判定依据一致（如「验证码、付款码、外卖订单，早就没用了」对应目录 / 时间启发式） |
| 3 | **第四原则「你的推翻我会记住」必须有真实实现** | `pages/62:139`；实现即 `APP-034` 的 `album_local_store` + `APP-036` 的推翻记录；若无实现则该条属虚假承诺 |
| 4 | 隐私卡口径与 37 / 60 页**逐字一致** | 同一红线的多处落地必须同口径 |
| 5 | 本页必须在 38 之前被看到 | `components.md:699`；这由入口关系保证（37 的 AI 卡 → 62 → 38），本任务在 62 上不放"直接跳过"的快捷路径 |
| 6 | 零网络 | D18 守卫 |

### 4.3 数据流

```text
进入 /album/ai
  → album_analysis.suggestions()          # 本机分析结果（仅已实现类别，带理由 / 张数 / 体积）
  → 合计 = Σ(已实现类别)
  → 未支持行由数据面的"未支持信号"驱动（APP-034 §4.2 裁决 6）
点击建议行 / CTA → push /album/manage
「整理原则」四条为静态文案（但与 APP-034/036 的真实能力一一对应）
```
