### 2.2 为什么必须做

1. **它是「一句话归位」这一产品承诺的执行面。** 生活页副标「说一句话，亚丝娜帮你归位」（`principles.md:92`）；`REQ-LIFE-01` 明确「统一入口，AI 判断归到哪个模块」（`requirements-analysis.md:266`）。没有本任务，捕获条只是装饰。
2. **它必须把「不建独立备忘录域」这条降级裁决封死。** `tasks.md:186` 与 `traceability.md:49`、`:213` 三处锁定：备忘录类输入统一落任务域（`kind=memo`），独立域列 **P2**。实现时极易「顺手做全」，本任务的 §3.2 是反范围护栏。
3. **它必须避免重复实现记账抽取链路。** `REQ-LEDG-07` 的抽取链（`PLA-007` / `PLA-008`）在 V4.0.0 **已交付**（`requirements-analysis.md:282`）；本任务**只做意图判定与分流**，重建抽取链会与既有链路分叉。
4. **它承载一条可判定规则——「不猜」。** 低置信时必须走**澄清候选**，**不得**默认归到某一类（用户明确要求）；这既避免错归，也让「归错可改归」有兜底。

### 2.3 在 V5.0.0 中的位置

M3 客户端第 6 个任务（`tasks.md:186`）。它消费 `API-005`（任务域，含 `kind=memo`）与 `API-007`（记忆上下文），是 `APP-015`（生活页捕获条）的**路由承接方**，与 `APP-014`（首页输入丸）/ `APP-011`（对话入口）以「只做跳转」解耦；记账侧**复用** V4.0.0 抽取链路与 `APP-013` 的过程卡展示。

## 3. Scope

### 3.1 In Scope

1. **意图路由契约**（§4.1.1）：输入 → 判定（服务端 AI）→ 分流到**记账 / 任务**。
2. **回执契约**（§4.1.2）：回执「**已归到 XX**」。
3. **改归契约**（§4.1.3）：归错时**一键改归**（撤销错误落库 + 重落目标域）。
4. **澄清契约**（§4.1.4）：低置信给**候选**让用户选，**不得静默猜测**。
5. **备忘录降级契约**（§4.1.5）：备忘录类输入统一落任务域 `kind=memo`；计数口径（供 `APP-015` 渲染）。
6. **复用抽取链路契约**（§4.1.6）：记账落库**复用** V4.0.0 链路，**不重建**。
7. **入口与边界契约**（§4.1.7）：`A17 capture` / 首页输入丸 / 对话入口的跳转边界。
8. **文案语气契约**（§4.1.8）：对齐 `principles.md` §5.2。
9. **红线自检**（§7.3）：无独立备忘录域 / 无抽取链重建 / 无硬编码色值 / 无 `*_enabled`。

### 4.3 数据流

```text
入口（三处，均只做跳转）
   · #life 快速捕获条（A17 capture，UI 归 APP-015）
   · 首页输入丸（UI 归 APP-014）
   · 对话页自然语言入口（UI 归 APP-011）
        → 收敛到 features/life/capture/capture_router（本任务）

capture_router
   → 提交文本 → 服务端 AI 判定（复用既有对话链路 / turn_meta.intention）
        · 判定结果 + 置信度（★ 置信度契约载体待冻结，§4.1.1）
   → 分流：
        高置信 + 记账 → 复用 V4.0.0 抽取链路（PLA-007/008）→ 落账本
        高置信 + 任务 → API-005 写 life_tasks
        高置信 + 备忘录 → API-005 写 life_tasks（kind=memo，D1 降级）
        低置信 → 澄清候选（不落库，D3）
   → 回执「已归到「记账」/「任务」」（就近展示）
   → 用户可「改归」→ 撤销错误落库（记账 reverse / 任务删）→ 重落目标域 → 回执「已改归到「XX」」（D4）

计数口径（D7）：
   「生活 · 备忘录」计数 = life_tasks 中 kind=memo 条数
   → APP-015 只渲染该计数（本任务定义口径与写入）

装配红线：
   ✗ 建独立备忘录域（D1）        ✗ 重建抽取链路（D2）
   ✗ 低置信默认归某一类（D3）     ✗ 改归以本地状态为准（D4）
   ✗ 端上做判定 / 关键词匹配（D5） ✗ 路由到日历 / 旅行 / 健康（D9）
```
