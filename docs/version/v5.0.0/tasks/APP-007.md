### 2.2 为什么必须做，且必须一次做全

1. **它是 M0 之后所有页面的唯一零件来源。** `APP-013`（过程卡）、`APP-014`（首页）、`APP-016`（记账页）、`APP-017`（记忆页）、`APP-020`（我的页）全部直接消费本任务产出；本任务若只做一半，下游会各自「临时补一个卡片」，直接击穿红线 1（渐变只用于 AI）与红线 2（禁止硬编码）。
2. **`A2 ai-card` 是本任务的**最大技术风险点**。** 它是全站视觉焦点（`components.md:16`），但 Flutter 的 `BorderSide` 不支持渐变 → 必须自绘 `CustomPainter`；若实现方式选错（如用 `ShaderMask`），会把子内容一起着色，且需额外反遮罩，成本更高（`flutter-architecture.md:311`）。
3. **它决定 golden 基建能否规模化。** `PLT-004` 要求 golden 覆盖「渐变描边卡、指标卡、任务行、账单行、记忆卡」（`tasks.md:217`），这些正是本任务的交付物。
4. **组件必须先于页面冻结。** M0 验收含「与设计稿截图比对无 M3 默认视觉特征」（`tasks.md:115`）——只有在组件层就把 M3 默认值关掉（`app/theme/` 覆盖 + 组件显式取值），页面层才不会漏。

### 2.3 在 V5.0.0 中的位置

M0 第 6 个任务，位于 `APP-005 → APP-007 → APP-013 → APP-014` 关键路径上（`tasks.md:246`）。它上承 APP-002 的 token，下接 APP-013 与 APP-014。

## 4. Technical Design Requirements

### 4.1 组件契约

#### 4.1.1 `GradientBorderCard`（`A2 ai-card` 的描边实现）★

| 项 | 契约 |
|---|---|
| 用途 | 承载「AI 结论」，**全站唯一允许渐变描边的卡片**（红线 1） |
| 描边几何 | `RRect`，圆角 = `AppRadii.lg`（24）；`strokeWidth = 1.5` |
| 描边着色 | `Paint()..style = PaintingStyle.stroke..strokeWidth = 1.5..shader = AppGradients.ai.createShader(rect)`；不透明度 `.55` |
| 子内容 | 内缩 **1.5px**，自身带 `surface` 白底，覆盖描边内侧 |
| 背景 / 圆角 / 内边距 / 投影 | `surface` · `rLg(24)` · `18` · `shadowCard` |
| **禁止** | 用 `ShaderMask`（会把子内容一起着色，需额外反遮罩，成本更高，`flutter-architecture.md:311`） |
| 复用红线 | **只有 `ai-card` 可用**；普通卡片加渐变描边 = 违反红线 1（`components.md:33`） |
| 内部结构 | `[✦ 图标 13px]` + 标签（12px/700 字距 .06em 色 `aiPrimary`）→ 正文（14.5px/1.75 色 `bodyOnCard`）→ 动作行（13px/600 色 `aiBlue`） |

#### 4.1.2 尺寸 / 圆角 / 投影 / 层级总表

| 维度 | 取值（全部来自 APP-002 的 `ThemeExtension`） |
|---|---|
| 圆角 | `rLg 24` / `rMd 18` / `rSm 12` / `rFull 999`；**图标底色方块圆角 = 边长 ÷ 3（取整）**：26→8、32→10、36→12、38→13、42→14（`tokens.md:116-137`） |
| 投影 | 常规 UI **只有一档** `shadowCard`；组件内不得引入第二档（`tokens.md:196`） |
| 间距 | 页面左右 18 / 卡内 18 / 中卡 13–16 / 卡间距 11–14 / 宫格 10–11 / 段间隔 24（`tokens.md:200-211`） |
| 层级 | 卡片 `surface` 在最底 → 内容在其上 → 描边在最外（`ai-card`）；虚线占位卡无投影（`A18 soon`） |
| 字号 | 走 `AppTypography` 6 级；字重按 `tokens.md:170-173` 降级映射（550→w500 / 650→w600 / 750→w700），**禁止在组件里直接写 `FontWeight.w550`** |
| 数字 | 一律 `AppTypography.numeric`（`FontFeature.tabularFigures()`），大额加 `letter-spacing: -0.02em` |

#### 4.1.4 组件 API 契约（统一形态）

| 项 | 契约 |
|---|---|
| 状态 | 无状态（`StatelessWidget` / `ConsumerWidget`） |
| 输入 | 纯数据 + 回调；不接收 `BuildContext` 之外的环境依赖 |
| 输出 | 无副作用；`onTap` 类回调由调用方注入 |
| 文案 | **不硬编码在组件内部**（为 V2 国际化留口，`requirements-analysis.md:226`）；由调用方传入，取值对齐 `principles.md §5.3` |
| 数字 | 数字型参数由调用方传入**已格式化字符串**或走 `AppTypography.numeric`，组件不做业务换算 |

### 4.2 关键裁决

| # | 裁决 | 理由 |
|---|---|---|
| D1 | **渐变描边自绘 `CustomPainter`（`RRect` + `stroke` + `shader`），不用 `ShaderMask`** | `Container.decoration.border` 不支持渐变；`ShaderMask` 会把子内容一起着色，需额外反遮罩（`flutter-architecture.md:311`；`requirements-analysis.md:193`） |
| D2 | **渐变描边只属于 `A2 ai-card`**，落点唯一 `GradientBorderCard` | 红线 1（`SKILL.md:42`）；`components.md:33` 明确「普通卡片加渐变描边 = 违反红线 1」 |
| D3 | 组件**必须无状态** | 有状态组件无法被 golden 稳定渲染，也无法被多页面安全复用 |
| D4 | 组件**不得 import `core/` 或 `features/`** | 分层纪律 L2（`flutter-architecture.md:196`）；否则 golden 需要网络 / 仓储桩，破坏可测性 |
| D5 | **数字一律走 `AppTypography.numeric`**，禁止页面手写数字样式 | 否则金额滚动时左右跳动（`flutter-architecture.md:329`；`tokens.md:182`） |
| D6 | 文案**沿用 skill 范例**，组件内不硬编码 | `tasks/README.md:67`；`principles.md:77-107` 是文案真源 |
