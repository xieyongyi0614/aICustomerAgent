## 3. Scope

### 3.1 In Scope

1. `_ModuleGrid` 补「相册」卡（`APP-033` 已扩为 3×3，本任务填实第 9 格）。
2. 摘要三态：`N 张 · 仅本机` / 未授权或零张 → `仅本机`（**无数字**）/ 读取失败 → 沿用 `life_page.dart:60` 的 `_unavailable` 文案并可重试。
3. **「仅本机」为不可省略的固定后缀**（红线 9）。
4. 点击 → `/album`。
5. 跨域张数通道：经**应用级状态 provider**（§4.2 裁决 1），由 album 域写入、life 域读取。
6. 权限未授予时**不触发权限弹窗**（生活页不申请相册权限；授权动作只在相册页发生）。

### 3.2 Out of Scope

| # | 不做 | 理由 |
|---|---|---|
| 1 | 在生活页申请相册权限 | 权限申请应发生在用户表达意图处（相册页）；在生活页弹权限会突兀，且违反最小必要 |
| 2 | 相册卡的"可清理张数"等 AI 结论 | 生活页摘要应短（`components.md:466`）；且 AI 结论属相册页 |
| 3 | 车辆卡的改动 | 归 `APP-033`（**同文件，不得并行编辑**） |
| 4 | 日历 / 旅行卡的处理 | 归 `APP-033`（D21） |
| 5 | 让 `life` 域直接 import album 域 | `layer_guards_test.dart:49` 守卫禁止 |
| 6 | 为相册张数新增后端端点 | `requirements-analysis.md` §2.4：相册**后端零需求且刻意为零**（红线 9 禁云同步） |
| 7 | 相册缩略图出现在生活页 | 无设计要求；且会带来生活页的图片解码开销 |

## 4. Technical Design Requirements

### 4.1 卡片契约

| 属性 | 值 |
|---|---|
| 组件 | `ModuleCard`（既有，`design_system/components/chips.dart`） |
| 标题 | 相册 |
| 摘要 | `{N} 张 · 仅本机`（有数据）/ `仅本机`（未授权或零张）/ `_unavailable`（读取失败） |
| 图标 | 相册 / 照片类（`APP-043` 补齐） |
| 语义色 | `warm` 浅底（与 `pages/30:162` 一致） |
| 点击 | → `/album` |

> **不可省略**：任何分支的摘要**都必须含「仅本机」**（`components.md:467` + `SKILL.md:52`）。

### 4.2 关键裁决

| # | 裁决 | 理由 |
|---|---|---|
| 1 | **相册张数经 `lib/app/state/` 的应用级 provider 传递，`life` 域不 import album 域** | `layer_guards_test.dart:49` 禁止跨域 import；而相册数据是端侧的（后端无端点），`APP-033` 的"own repository 直连后端"解法不适用。**经应用级状态传递**是唯一同时满足"不跨域 import""不需后端""不违反 core→features 禁令（`layer_guards_test.dart:79`）"的通道；`lib/app/state/` 已存在（`persona_mode.dart`）且不受现有守卫限制 |
| 2 | **「仅本机」在任何分支都必须出现** | `components.md:467` + `SKILL.md:52` 红线 9；这是本卡区别于其他模块卡的强制性文案 |
| 3 | **未授权时不显示数字、且不弹权限** | 权限申请归相册页（§3.2 #1）；未授权时张数未知，显示数字即为编造 |
| 4 | 零张时也不显示 `0 张` | 与 `APP-033` §4.2 裁决 3 同口径（空态不给数字） |
| 5 | 读取失败只降级该卡 | 沿用 `life_page.dart:49-54` 的分块失败标记 |
| 6 | **与 `APP-033` 串行执行** | 两者改同一文件（`life_page.dart`）；并行编辑会互相覆盖 |
| 7 | provider 的写入方是 album 域（`APP-034`/`APP-035`），life 域只读 | 方向单一，避免双向依赖 |

### 4.3 数据流

```text
【写入方 · album 域】
  相册页授权并读到张数
    → app/state/album_summary_provider（应用级）写入 {count, authorized}

【读取方 · life 域】
  进入 /life → _load()（life_page.dart:29）
    → 读 album_summary_provider
         ├─ authorized 且有数据 → 「N 张 · 仅本机」
         ├─ 未授权 / 零张        → 「仅本机」
         └─ 失败                → _unavailable + 重试
  ✗ life 域不 import features/album（守卫强制）

【跳转】
  点击相册卡 → push /album（相册页负责申请权限）
```

### 4.4 依赖与边界

| 允许依赖 | 禁止依赖 |
|---|---|
| `design_system/components/**`（`ModuleCard`） | **`features/album/**`**（跨域禁令 `layer_guards_test.dart:49`） |
| `lib/app/state/**`（应用级 provider，新增） | `package:dio`（presentation） |
| `features/life/data/life_repository.dart`（既有） | `core/storage/**` 的 `LocalStores` |
