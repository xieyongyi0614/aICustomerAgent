## 2. Background

| 组件 | skill 位置 | 端侧现状 |
|---|---|---|
| A36 `storage`（本地存储卡） | `components.md:355-358` | **无** |
| A36 `album`（相簿卡，2 列宫格） | `components.md:359-361` | **无** |
| A36 `photo`（照片格，3 列） | `components.md:362-365` | **无**（含**选择模式**与**AI 保留原片 opacity .55** 两条状态） |

**图标缺口（实测）**：`app_icons.dart:10-48` 的注册清单**没有**相册 / 照片 / 相机 / 盾牌以外与相册相关的图标；三页需要至少 5 个（相册、照片、平板截图、相似叠影、重复下载、盾形、播放、对勾、标签、移动）。实测清单中**已有** `shield`、`check`、`download`、`arrowLeft`、`sun`、`lock`，缺相册 / 照片 / 截图 / 相似 / 播放 / 标签 / 移动类。

**设计纪律（来自 skill）**：
- `components.md:358`：`storage` 底部说明必须带「仅本机存储 · 未开启任何云同步」（**红线 9**，`SKILL.md:52`）。
- `components.md:364`：**选中态复选框允许 ai 渐变**（全站唯一允许非 AI 元素用渐变的例外，已在 skill 明文授权）。
- `components.md:365`：**被 AI 保留的相似原片 opacity .55**，与「AI 预选待删」形成对照。
- `components.md:370`：`actionbar` 底部常驻一行隐私口径「删除只在本机生效 · 最近删除 30 天可恢复」。
- `components.md:371-373`：照片占位渐变 `g1`~`g8` **是原型专用**，实现时**替换为真实缩略图**。

## 3. Scope

### 3.1 In Scope

1. **A36 `StorageCard`**：白卡 `rLg` / 内边距 18；数值 22px/750（单位 12px `ink3`）+ 右侧剩余空间 12px `ink3`；占用条高 7 / `rFull` / 轨道 `trackBar` / 填充 `barPurple`；底部说明 11.5px `ink3` + 12px 盾形图标（`health` 色）+ 固定文案「仅本机存储 · 未开启任何云同步」。
2. **A36 `AlbumTile`**：2 列宫格 / 间隙 11 / 白卡 `rMd` / 内边距 9；封面高 86 / 圆角 12（**真实缩略图**，不接受渐变占位）；名称 13.5px/650；数量 11px `ink3`，可带 AI 结论（如「402 张 · 38 张可清理」）。
3. **A36 `PhotoTile`**：3 列 / 间隙 6 / 1:1 / 圆角 12；**选择模式**右上 chk 22px（未选 = 白底 85% + 1.5px `borderCheck`；选中 = 2.5px `aiPrimary` 描边 + ai 渐变底白对勾）；**AI 保留原片** `opacity .55`；可选时长徽章（视频）。
4. **A36 `AlbumActionBar`**：底部固定 / 底 `rgba(255,255,255,.94)` + 18px 模糊 / 上边线 `line`；内边距 14-16-26 / 按钮行间隙 10；按钮 `flex 1` / 底 `fillSubtle` / 13.5px/650 / `rFull` / 内边距 12 / 图标 15px；**危险项**底 `rgba(240,106,106,.12)` 字 `#E05252`；**底部常驻盾形口径行**（11px `ink3`）。
5. **A38 `SuggestionRow`**：容器白卡 `rLg` / 内边距 6-18；行内边距 15-0 / 分割线 `line` / **末行无分割线** / 整行可点；图标方块 42px / 圆角 14 / 语义浅底；标题 14.5px/600 + 理由 11.5px `ink3`；右侧双行（数量 14.5px/700 / 体积 11px `ink3`，均 `tabular-nums`）。
6. `app_icons.dart` 补相册域图标（≥5 个）并走生成器 + cmap 守卫。
7. barrel 导出 + golden（含 `PhotoTile` 三态、`ActionBar` 危险项）。
8. token 缺口补齐（`trackBar` / `barPurple` / `borderCheck` / `fillSubtle` 等）。

## 4. Technical Design Requirements

### 4.1 组件契约

| 组件 | 关键参数（语义） | 备注 |
|---|---|---|
| `StorageCard` | `{assetCount, leftoverText, usedBytes, totalBytes, usageRatio}` | 「仅本机存储 · 未开启任何云同步」文案**内置**，不可被调用方替换（红线 9） |
| `AlbumTile` | `{thumbnail, name, countText, badgeText?, onTap}` | `thumbnail` 为必填图片源，**无渐变兜底** |
| `PhotoTile` | `{thumbnail, selectionMode, selected, aiKept, durationText?, onTap, onToggle}` | `aiKept` 与 `selected` 互斥语义由调用方保证 |
| `AlbumActionBar` | `{actions: [AlbumAction(label, iconKind, danger, onTap)]}` | 底部盾形口径行**内置**，不可替换 |
| `SuggestionRow` | `{iconKind, accent, title, reason, countText, sizeText, onTap}` | `reason` 必填（`components.md:396` 纪律） |

**层级约束**：`design_system/**` 不得 import `core/` 或 `features/`（`layer_guards_test.dart:67`）。

### 4.2 关键裁决

| # | 裁决 | 理由 |
|---|---|---|
| 1 | **`StorageCard` / `AlbumActionBar` 的隐私口径文案内置在组件内** | 红线 9 是**每个相册页面**的强制项（`SKILL.md:52`）；做成参数会被漏传，做成内置则漏不掉 |
| 2 | **选中态允许 ai 渐变，其余一律中性色** | `components.md:364` 明文授权；这是全站唯一例外，须在组件内注释/命名上标明边界（并被用例锁定） |
| 3 | **`PhotoTile` 不提供渐变占位兜底** | `components.md:371`：占位渐变是原型专用 |
| 4 | **`AlbumActionBar` 的危险项**必须用 skill 给定的色值（`rgba(240,106,106,.12)` / `#E05252`），经 token 取用 | `components.md:369`；`SKILL.md:45` 禁散落硬编码 |
| 5 | **`SuggestionRow` 的数值必须成对出现**（张数 + 体积） | `components.md:396` 纪律「不能只给类型名与数量」 |
| 6 | 图标必须走生成器 + cmap 守卫 | `apps/mobile/README.md:150` + `docs/icons.md` |
| 7 | 缩略图按需解码，组件不预载全量 | 缺口 28 的性能约束（`requirements-analysis.md` §3.5）；`PhotoTile` 内使用 `cacheWidth` 等按需解码手段 |
