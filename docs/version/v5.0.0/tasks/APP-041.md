严格照 §3.1 的 skill 数值实现；对外只暴露**语义参数**，不暴露像素：

| 组件 | 关键参数（语义） |

| `LedgerSeg` | `{options: [(value, label)], value, onChanged}` |

**层级约束**：`design_system/**` **不得** import `core/` 或 `features/`（`layer_guards_test.dart:67`）；组件不得持有业务逻辑或网络调用。

### 4.2 关键裁决

| # | 裁决 | 理由 |
|---|---|---|
| 1 | 记账域选中色用 **`money` 色 55% 透明**（`rgba(239,166,60,.55)`），非 `aiPrimary` | `components.md:308` 明文；AI 渐变只属 AI 元素（`SKILL.md:44` 红线 1） |
| 2 | `LedgerSaveButton` 用 **`ink` 深色**，不用 ai 渐变 | `components.md:315`：保存是用户动作 |
| 3 | 金额**必须** `FontFeature.tabularFigures()` | `SKILL.md:81`：不加会让金额滚动时左右跳动 |
| 4 | 金额与所有数值类文本一律等宽 | 同上；A33 `stat` 的 19px/750 与 A31 副文案亦适用 |
| 5 | `LedgerConfirmRow` 的「确认」用 `health` 底白字、「修改/忽略」用 ghost | `components.md:324-325` |
| 6 | 组件内**零硬编码色值**，全部经 `context.colors` / tokens 取用 | `SKILL.md:45` 红线 2 + `layer_guards_test.dart:94` 守卫 |
| 7 | 不做 `pumpAndSettle` 类无限动画（光标闪烁用有限 `AnimationController` 并在 `TickerMode` 内） | 与 `APP-006` Orb 的功耗纪律一致；golden 需可稳定截图 |
