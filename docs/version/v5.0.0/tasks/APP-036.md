## 3. Scope

### 3.1 In Scope

1. `album_manage_page.dart`：照 B15 的 6 段。
2. 路由 `/album/manage`（`chromeImmersive`）+ 可接 `?album=` 限定相簿（供 `APP-037` 的「批量管理这个相簿」）。
3. 顶栏计数（实时「已选 N 张」）+ 全选 / 取消。
4. AI 预选提示 + 回指 `/album/ai`。
5. 分组照片墙：
   - **过期截图**（AI 预选，可推翻）
   - **重复保存**（AI 预选，可推翻）
   - **相似连拍**：按 D16 呈**诚实未支持态**（说明本期不做 + 不提供预选 + 不计入删除数）
   - **手动挑选**（无预选）
6. AI 未选的原片 `opacity .55` 且**可见可点**（可手动改选）。
7. 批量操作：移动相簿 / 加标签 / 删除（走系统能力，D17）。
8. 预选推翻**被记住**（`APP-034` 的端侧存储）；再次进入时不再预选被推翻的项。
9. 零网络。

## 4. Technical Design Requirements

### 4.1 页面契约（照 `components.md:647-659` B15）

| # | 段 | 组件 | 内容 |
|---|---|---|---|
| 1 | 顶栏 | 自定义顶栏 | 左「取消」（回 37）/ 中「已选 N 张」15.5px/700 / 右「全选」`aiBlue` |
| 2 | AI 提示条 | `AiCard` 单行变体 | `[✦]`「已帮你预选 N 张：… 都在本机分析」 |
| 3 | 回指链接 | 文本链接 | 「这些预选是怎么算出来的 →」→ `/album/ai` |
| 4 | 分组 · 过期截图 | `_GroupLabel` + `PhotoTile` 网格 | 预选 = ai 渐变对勾 + `aiPrimary` 描边 |
| 5 | 分组 · 重复保存 | 同上 | 同上 |
| 6 | 分组 · 相似连拍 | `_GroupLabel` + **诚实未支持说明** | **不渲染照片墙**（无预选、无张数） |
| 7 | 分组 · 手动挑选 | `PhotoTile` 网格（部分选中） | 无预选 |
| 8 | 操作栏 | **`AlbumActionBar`（A36）** | 移动 / 加标签 / 「删除 N 张」（危险色）+ **内置**常驻口径行 |

> **数值口径**：以 `components.md:688`（B17）与 `pages/` 的自洽口径为准（`76 = 过期截图 38 + 相似连拍 26 + 重复保存 12`）；由于相似连拍本期不做，**本页实际候选总数 = 过期截图 + 重复保存**，AI 提示条与删除计数**按实际候选数**给出，不写死。

### 4.2 关键裁决

| # | 裁决 | 理由 |
|---|---|---|
| 1 | **相似连拍分组呈诚实未支持态，且不计入任何计数** | D16（缺口 24）；渲染假张数直接违反 `APP-014` 红线 |
| 2 | **数值以 B17 / `pages/` 的自洽口径为准**（冲突 15） | skill B14/B15 的「12 张 / 8 张 / 4 张」是旧稿残留，与 B17/B18 及 `pages/` 全部不一致；端侧不擅改 skill，但**不回退到错误口径**，并把 skill 回写登记为待办（`traceability.md` §13.5 V1） |
| 3 | **AI 未选的原片必须可见**（`opacity .55`） | `components.md:659`：「预选永远可推翻，删除主动权在用户」。隐藏未选原片会让"AI 替我决定"成立，与产品立场相反 |
| 4 | **推翻会被记住** | `pages/62:139` 的整理原则之一；无此能力则原则落空 |
| 5 | 删除走**系统能力**，不自行移动文件 | D17；自建回收站需复制原图，与"省空间"矛盾 |
| 6 | 「加标签」的标签集为**端侧自填**（无设计稿标签库） | `pages/38:157` 只有「加标签」按钮；编造标签库属虚构 |
| 7 | 零网络 | D18 守卫 |

### 4.3 数据流

```text
进入 /album/manage（可带 ?album=）
  → album_repository.loadGroups(album?)      # 分组候选（含 analysis 结果）
  → 应用「推翻记录」（album_local_store）过滤预选
选中 / 取消 → 本地状态 + 写入推翻记录（仅取消时）
「删除 N 张」
  → album_repository.delete(assets)          # 系统能力 → 系统「最近删除」
  → 回到 37 并刷新计数
「移动」→ 选择目标相簿 → repository.move(...)
「加标签」→ 端侧标签输入 → album_local_store
回指「这些预选是怎么算出来的」→ push /album/ai
```
