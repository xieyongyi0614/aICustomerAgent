### 2.2 为什么必须做，且必须在 M0 做

1. **它是「AI 存在感」的唯一视觉载体。** 设计稿把「SAO 式 10% 科技感」全部倾注在 Orb 上（`orb.md:4`）；其余区域一律克制（`principles.md:32-34`）。没有 Orb，「一个正在为我做事的 AI」在设计语言上不成立。
2. **它是 M0 收口点 C1 的一部分。** C1 判定标准含「Orb 四态可切」（`tasks.md:255`），且 M0 验收口径明确「Orb 四态可在调试面板手动切换」（`tasks.md:115`）。
3. **它必须早做，因为它决定 golden 基建。** `flutter-architecture.md:363` 明确「golden 测试必须覆盖四态 × 两尺寸，因为它是全站唯一『AI 语义』承载者，视觉回归成本最高」——Orb 是 golden 基建的第一个真实负载。
4. **它的功耗处理不能后补。** `saveLayer` 开销大（`orb.md:117`），若先用「能跑就行」的写法上线，后续在首页首屏常驻会持续耗电，返工成本高于一开始就按分层要求实现。

### 2.3 在 V5.0.0 中的位置

M0 第 4 个任务，位于 `APP-001 → APP-002 → APP-006` 链上（`flutter-architecture.md:428`）。它的下游是 `APP-012`（人格状态栏迷你 Orb）、`APP-014`（首页 Hero Orb）、`APP-018`（简报页 Orb 行）、`APP-024`（健康 Hero Orb）——这些任务**只消费 Orb，不得各自复制一份绘制逻辑**。

## 3. Scope

### 3.1 In Scope

1. **Orb widget（`Orb(size, state)`）**：接收尺寸档与四态，内部自管动画控制器；**不接收业务数据**。
2. **三档 Orb 尺寸**：`lg 76` / `md 34` / `sm 22`（`orb.md:61-68`）。
3. **四态语义与配色**：待机 / 思考 / 主动关怀 / 完成（`orb.md:72-91`）。
4. **待机态视觉规格 1:1 落地**（`orb.md:24-57`）：

   | 层 | 规格 |
   |---|---|
   | 底层 | 圆形径向渐变，圆心 32% 28%；4 个 stop：`#D9CCFF 0%` → `#8B6DFF 34%` → `#4D6BFF 66%` → `#1FB9D8 100%` |
   | 内描边 | `inset 0 0 0 1px rgba(255,255,255,.5)` → `strokeWidth 1`、白色、不透明度 `.5` |
   | 外发光 | `0 10px 30px rgba(102,90,255,.45)` + `0 0 60px rgba(63,150,255,.35)` |
   | 内层 A | 圆心 68% 72%，`rgba(43,210,232,.85)` → `transparent 46%` |
   | 内层 B | 圆心 30% 26%，`rgba(255,255,255,.90)` → `transparent 30%` |
   | 内层叠加模式 | `BlendMode.screen` |
   | 内层旋转 | 7s 线性无限旋转（`rotate 0 → 360deg`） |
   | 呼吸 | 4.2s ease-in-out 无限循环，`scale 1 → 1.055 → 1` |

5. **四态推导配色**（`orb.md:83-88`）：

   | 态 | 径向渐变（圆心 32% 28%） |
   |---|---|
   | 待机 / 陪伴 | 蓝紫（§3.1 第 4 条） |
   | 思考 / 执行 | 蓝紫 + conic 色相流动 |
   | 主动关怀 | `#FFE6D2 0% → #FFB48F 36% → #FF9D76 68% → #FF7A4D 100%` |
   | 完成 / 成长 | `#C8F7E4 0% → #6FD9B4 36% → #33BC8C 68% → #1F9A70 100%` |

6. **四态动效**：待机呼吸 4.2s + swirl 7s；思考呼吸幅度加大至 1.08、swirl **加速至 2.4s**、叠加 conic 旋转；主动关怀非对称脉冲 **1.8s**（快起慢落）；完成一次性绽放 **600ms**（`scale 1 → 1.18 → 1`）。
7. **两条状态纪律**（写入裁决 D3 / D4）：完成态播完**必须回到待机**；同一时刻**只有一态**，冲突时优先级 `完成 > 主动关怀 > 思考 > 待机`。
8. **渲染与功耗**：`RepaintBoundary` + `CustomPainter` + 两个 `AnimationController`（`useAnimationController`）；`saveLayer` 只在可见时执行；呼吸用 `Transform.scale` 包外层**不重绘 painter**；painter 内缓存 `Path` / `Shader`；`TickerMode` 感知停表；首页长列表滚动时降频或暂停（接口留给调用方）。
9. **无障碍**：`Semantics(label: '亚丝娜，AI 助手')`。
10. **golden 基线**：四态 × 两尺寸（`lg 76` / `md 34`）共 8 张，作为 C1 的视觉回归锚点。

## 4. Technical Design Requirements

### 4.1 组件契约

#### 4.1.1 尺寸档（`orb.md:61-68`）

| 档 | 尺寸(px) | 出现位置 | 本任务是否交付 |
|---|---|---|---|
| `lg` | 76 | 首页 Hero 区（居中） | ✅ |
| `md` | 34 | 对话页头像、健康 Hero、人格卡、简报页 | ✅ |
| `sm` | 22 | 消息流中的 AI 头像（每条 AI 气泡旁） | ✅ |
| 悬浮球 | 56 | 底部 Tab 栏中间 | ❌ **非 Orb**，归 A9（APP-005） |

#### 4.1.2 四态契约（`orb.md:72-91`）

| 态 | 语义 | 配色 | 呼吸 | swirl | 附加动效 | 触发场景 |
|---|---|---|---|---|---|---|
| `idle` 待机 / 陪伴 | 安静存在 | 蓝紫（§3.1 第 4 条 4 stop） | 4.2s，`scale 1→1.055` | 7s 线性 | — | 首页 Hero、对话头像（默认） |
| `thinking` 思考 / 执行 | 正在为你做事 | 蓝紫 + conic 色相流动 | 幅度加大至 **1.08** | **加速至 2.4s** | 叠加 conic 渐变旋转 | 工具调用进行中（配合 `A14 proc`） |
| `caring` 主动关怀 | 我要跟你说件事 | 暖橙（`#FFE6D2 → #FFB48F → #FF9D76 → #FF7A4D`） | 非对称脉冲 **1.8s**（快起慢落） | 停用 | — | 早间简报、异常提醒 |
| `done` 完成 / 成长 | 做完了 / 长大了 | 青绿（`#C8F7E4 → #6FD9B4 → #33BC8C → #1F9A70`） | 单次 | 停用 | 一次性绽放 `1 → 1.18 → 1`，**600ms**，只播一次 | 任务完成、记忆新增、关系升级 |

#### 4.1.3 状态机契约（输入 / 输出 / 优先级）

| 项 | 契约 |
|---|---|
| 输入 | `state`（四态枚举）；`size`（三档枚举） |
| 完成态重置 | 组件内自持「一次性」语义：绽放播完 → 自动回 `idle`；**不需要外部重置信号**（外部再置 `done` 会重新触发一次绽放） |
| 优先级 | `done > caring > thinking > idle`。多态同时被请求时，高优先级胜出（裁决 D4） |
| 动画控制 | `thinking` 才启用 swirl；`caring` / `done` 停用 swirl；`done` 播完停用全部循环并回 `idle` |
| 可见性 | 页面不可见 / App 进后台 → **停表**（`TickerMode`）；恢复可见后按当前 `state` 续播 |

#### 4.1.4 渲染分层契约（`orb.md:97-127`；`flutter-architecture.md:337-343`）

| 层 | 契约 |
|---|---|
| `Orb` widget | `HookConsumerWidget` 或 `HookWidget`（二选一，**不与 `StatefulWidget` 混用**，`flutter-architecture.md:56`） |
| `RepaintBoundary` | 必须包裹 `CustomPaint`，隔离重绘（`orb.md:101`） |
| `CustomPaint(painter: OrbPainter(progress, state))` | painter **只依赖 `state`**；呼吸进度不进 painter |
| 呼吸实现 | `Transform.scale` 包外层，**不重绘 painter**（`orb.md:114`） |
| `saveLayer` | 仅在 `Orb` 可见时执行内层 screen 叠加；不可见时不进入该分支 |
| painter 缓存 | `Path` / `Shader` / `RadialGradient` 在 painter 构造期缓存，`paint()` 内**禁止逐帧重建**（`orb.md:126`） |
| 内描边 | `Paint()..style = PaintingStyle.stroke..strokeWidth = 1` 画 1px 白圈，不透明度 `.5` |
| 旋转 | 对整个内层做 `canvas.rotate(angle)`，**不逐帧重算渐变坐标**（`orb.md:113`） |
| 长列表降频 | Orb 暴露「暂停 / 降频」开关给调用方（首页滚动时由 APP-014 调用） |

#### 4.1.5 无障碍与语义契约

| 项 | 契约 |
|---|---|
| 语义标签 | `Semantics(label: '亚丝娜，AI 助手')`（`orb.md:131`） |
| 动态字号 | Orb 为图形，不随系统字号缩放（保持像素尺寸）；但其**相邻文案**由调用方负责 200% 不破版（`tokens.md:263`） |
| 装饰性 | Orb 不承载关键信息（状态语由文本承载），故不设 `Semantics(value:)` 状态播报 |

### 4.2 关键裁决

| # | 裁决 | 理由 |
|---|---|---|
| D1 | **悬浮球（56）不进 Orb 组件**，归 A9 / APP-005 | 二者视觉（径向 vs 线性）、动效（呼吸 vs 无）、语义（生命体 vs 按钮）完全不同（`orb.md:12-20`）；合并会同时踩两条纪律 |
| D2 | **呼吸用 `Transform.scale` 包外层，painter 只依赖 `state`** | 若把呼吸进度传进 painter，等于每帧重建渐变 → 掉帧（`orb.md:114`） |
| D3 | **完成态播完必须回到待机** | 停在青绿会让「AI 永远在庆祝」，状态语义失真（`orb.md:90`） |
| D4 | **同一时刻只有一态**，优先级 `完成 > 主动关怀 > 思考 > 待机` | 多态叠加会产生无定义视觉；优先级由设计系统冻结（`orb.md:91`） |
| D5 | 两个 `AnimationController` 用 **`useAnimationController`** | 这是 `flutter-architecture.md:54` 明确列为 hooks 的**合规用法**；同时**禁止**用 `useState` 存业务状态、禁止与 `StatefulWidget` 混用（`flutter-architecture.md:52-57`） |
| D6 | `saveLayer` + `BlendMode.screen` 必须配 `RepaintBoundary`，且只在可见时执行 | `saveLayer` 开销大（`orb.md:117`）；首页首屏常驻，不隔离会带动整页重绘 |
| D7 | Orb 尺寸**只三档 76 / 34 / 22**，不新增中间档 | 尺寸档由设计系统冻结（`orb.md:61-68`）；随手加档会让 golden 基线失控 |
| D8 | 所有色值经 `ThemeExtension`，**禁止 `Color(0x...)`** | 红线 2（`SKILL.md:43`）；C1 验收即「全仓 grep 无硬编码色值」（`tasks.md:255`） |
| D9 | 动效时长：呼吸 4.2s 与 swirl 7s 是**唯一例外**，其余 ≤400ms | 设计系统纪律（`tokens.md:235`）；完成态 600ms 属一次性绽放，不计入循环动效约束 |
| D10 | 不实现光晕表情（P2）与 3D 形象（🚫） | 反范围（`orb.md:141-142`；`traceability.md:150`） |
| D11 | Orb **不接收业务数据**，只接收 `state` | 保证 `design_system/` 与业务解耦、可 golden 单测（分层纪律 L2，`flutter-architecture.md:196`） |

### 4.3 数据流

```text
业务侧（features/chat | features/home | features/briefing | features/health）
   ↓ 计算当前态（由 ChatEvent / tool_step / 任务完成事件推导，属 APP-013 / APP-014 职责）
Orb(size: lg|md|sm, state: idle|thinking|caring|done)
   ↓ hooks：useAnimationController × 2（Breathe 4.2s / Swirl 7s）
   ↓ TickerMode（不可见 → 停表）
   ↓ Transform.scale（呼吸，不重绘 painter）
RepaintBoundary
   └── CustomPaint(painter: OrbPainter(progress, state))
         ├── 底层径向渐变（4 stop，圆心 32% 28%）
         ├── saveLayer(bounds, Paint())        ← 仅可见时
         │     ├── 内层 A（screen）
         │     ├── 内层 B（screen）
         │     └── canvas.rotate(angle)        ← swirl
         └── 内描边 1px 白（stroke）
```

**无网络、无仓储、无业务依赖**——Orb 是纯渲染组件（分层纪律 L2）。

## 7. Testing Requirements

> 分层对齐 `flutter-architecture.md:382-392`：单元 / golden / widget / 契约回放。Orb 无网络事件依赖，**契约回放层不适用**（由 APP-013 覆盖 `tool_step` 回放）。

### 7.1 单元（纯 Dart）

| 用例 | 断言 |
|---|---|
| `test_priority_done_beats_all` | 同时请求 `done` 与 `caring/thinking/idle` → 生效态为 `done` |
| `test_priority_caring_beats_thinking_and_idle` | 同时请求 `caring` 与 `thinking/idle` → `caring` |
| `test_priority_thinking_beats_idle` | 同时请求 `thinking` 与 `idle` → `thinking` |
| `test_done_returns_to_idle_after_bloom` | 绽放动画结束后 `state == idle`（**不停留在青绿**） |
| `test_done_replay_when_set_again` | 回到 `idle` 后再次置 `done` → 重新播放一次绽放 |
| `test_swirl_enabled_only_in_thinking_and_idle` | `thinking`/`idle` 启用 swirl；`caring`/`done` 停用 |
| `test_thinking_swirl_duration_is_2_4s` | 思考态 swirl 周期 = 2.4s（非 7s） |
| `test_breath_duration_is_4_2s` | 呼吸周期 = 4.2s（**不取 4.0s**） |
| `test_bloom_duration_is_600ms` | 完成态绽放时长 = 600ms |
