- `components.md:338`：**深色卡上的进度条用 warm / 白系浅色，禁止用 ai 渐变**（进度不是 AI 语义）。

- `components.md:385`：**时间线末行必须是「即将发生」态**，让用户一眼看到下一步。
- `components.md:383`：未发生态的右侧值用 12px/650 `#E07B4F`。

## 4. Technical Design Requirements

### 4.1 组件契约

| 组件 | 关键参数（语义） | 备注 |
|---|---|---|
| `LoanCard` | `{label, badgeText, remainingText, subText, progress (0..1), leftNote, rightNote}` | 进度填充用 warm 渐变常量，**不接受外部色**（防误用 ai 渐变） |
| `TypeScroll` | `{items: [(key, label, iconKind, accent)], selectedKey, onSelected}` | `accent` 为各类型语义色 |
| `Timeline` | `{items: [TimelineItem(iconKind, accent, title, subtitle, valueText, isUpcoming)]}` | 末项 `isUpcoming` 由**调用方保证**；组件不做排序 |
| `TimelineItem` | 同上 | — |

**层级约束**：`design_system/**` 不得 import `core/` 或 `features/`（`layer_guards_test.dart:67`）。

### 4.2 关键裁决

| # | 裁决 | 理由 |
|---|---|---|
| 1 | `LoanCard` 的进度填充**硬编码在组件内为 warm 渐变常量**，不暴露颜色参数 | `components.md:338` 是明文禁令；暴露参数等于把违规可能交给调用方 |
| 2 | `TypeScroll` 的选中描边色由**每项的 `accent`** 派生（55% 透明） | `components.md:348`；六类型各有语义色（充电 health / 加油 warm / 里程 ai2 …） |
| 3 | `Timeline` **不自动排序、不自动判定末项** | 组件只负责渲染；"末行必须是未发生态"是**调用方的数据契约**（由 `APP-032` 保证并被用例断言） |
| 4 | 未发生态色值取 skill 明文 `#E07B4F`，**经 token 取用** | `SKILL.md:45` 红线 2（禁散落硬编码）；若 token 无此值则先在 token 层新增（不是组件内写死） |
| 5 | 图标**必须**走生成器流程 | `apps/mobile/README.md:150` + `docs/icons.md`；手抄码点会被 cmap 守卫测试抓住 |
| 6 | 时间线值一律 `tabular-nums` | `SKILL.md:81`（数字滚动不跳动） |
