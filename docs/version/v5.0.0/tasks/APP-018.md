### 2.2 为什么必须做

1. **它是「主动但克制」的落地页。** 决策 D4 选本地通知的完整链路是「本地通知触发 → 点击 → 落到简报页」（`requirements-analysis.md:374`）；没有本页，通知点击无落点，「主动」只剩通知横幅。
2. **它是 M3 收口点 C4 的一半。** C4 判据「本地通知准时、可关、不重复」（`tasks.md:258`）中，「准时」的观感来自本页能否在设定时刻呈现正确形态的内容；`APP-019` 负责触发，本页负责承接。
3. **两种形态共用布局是明确的设计约束。** `components.md:439` 与 `tasks.md:182` 双重锁定：晚间总结复用同一布局，只换收尾语与卡片。若实现成两套页面，后续卡片增删会双倍维护。
4. **它携带一处易漏项——状态栏颜色还原。** `components.md:99` 要求简报页状态栏文字转白；深色页返回浅色首页时若忘记还原，首页状态栏会「白字压白底」不可读。本任务把它写成 AC（§8 AC3）。

### 2.3 在 V5.0.0 中的位置

M3 客户端第 1 个任务（`tasks.md:182`）。它消费 `API-008`（内容）与 `APP-006`（Orb），被 `APP-019`（本地通知点击落地）依赖，与 `APP-020`（主动关怀开关）共享「可关」语义，与 `APP-014`（首页 AI 总结卡跳转）对接。

#### 4.1.2 两种形态切换契约（★ 共用一套布局）

| 维度 | 早间形态（`type = morning`） | 晚间形态（`type = evening`） |
|---|---|---|
| 眉标 | 「08:00 · 早间简报」 | 「21:30 · 晚间总结」 |
| 主标题 | 「早上好，<br>我整理好了你的今天。」 | 「晚上好，<br>今天也辛苦了。」（**待定**，见下） |
| Orb 解读 | 「昨晚你睡了 7 小时 12 分，比前几天都好。今天可以安排点硬仗。」 | 回顾式解读（如「今天完成了 2 件事，睡了 7h12m 的底子在，明天可以更稳」；**待定**，须沿用 `principles.md` §5.3 语气） |
| 卡片集合 | **前瞻型**：天气 / 今日日程 / 任务提醒 / 生活节奏（`components.md:433-434`） | **回顾型**：完成的事 / 花了多少 / 睡得如何（`components.md:439`）+ 第四张（**待定**，须为回顾语义） |
| 收尾语 | 「开始今天」 | 「安顿明天」 |
| 未完成任务处理 | 列出今日待办（含 AI 排序理由） | **由 AI 重新排期而非催促**（`tasks.md:181`；语气规则 5 `principles.md:74`）——卡片文案须写「我把 X 挪到了明天上午」，**禁止**「你还没做 X」类催促措辞 |
| 布局 | 与晚间**完全相同**（同一 widget 树，按 `type` 取数据与文案） | 同左 |

| 项 | 契约 |
|---|---|
| 形态判定 | 由 `API-008` 返回的简报 `type` 决定（`morning` / `evening`）；端上**不得**按当前时刻自行推断（避免「08:00 打开却显示晚间」） |
| 单一渲染入口 | 两种形态**共用同一个页面 widget**，差异只经 `type` 分支取文案与卡片集合；**禁止**复制出两个页面文件 |
| **待定 + 阻塞条件** | 晚间主标题、Orb 回顾解读、第四张回顾卡**在 `components.md:439` 只给了语义（「回顾型」）未给逐字文案**。这三处**须在 `API-008` 的 Detail 中冻结逐字文案**（服务端预生成，端上不写死），否则端上自创文案违反「文案不自创」纪律。**`API-008` 未冻结前，晚间形态不得开工**。 |

### 4.2 关键裁决

| D1 | 早间 / 晚间**共用一套布局**（同一 widget，按 `type` 分支） | `components.md:439`、`tasks.md:182` 双重锁定；两套页面会双倍维护 |

### 4.3 数据流

```text
本地通知点击（APP-019）
   → 深链 #briefing?type=morning|evening
   → features/briefing/presentation/briefing_page
        → features/briefing/data/briefing_repository（L3：presentation 不得直调 dio）
             · GET（API-008）→ {type, greeting, title, orb_note, cards[], cta, generated_at}
        → drift 只读缓存（进页先渲染缓存，再刷新；离线命中标注数据时间）
        → Riverpod provider
        → 按 type 取「眉标 / 主标题 / Orb 解读 / 卡片集合 / 收尾语」
        → 渲染：deepBrief 背景 + 白字 + 无 Tab 栏 + 状态栏转白
        → 离开时复位状态栏样式

装配红线：
   ✗ 不用 deepSummary / deepPersona（D2）
   ✗ 不按时刻推断形态（D3）
   ✗ 不端上拼装结论文案（D4）
   ✗ 晚间不出现催促措辞（D5）
   ✗ 含健康数值却无免责（D8）
```
