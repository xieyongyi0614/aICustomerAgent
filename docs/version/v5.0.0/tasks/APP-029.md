## 3. Scope

### 3.1 In Scope

1. 在 AI 观察卡之后插入 A31 双入口（两张并排）。
2. 左卡「手动记一笔」/ 副文案「金额 + 分类，备注我帮你填」→ `/ledger/add`。
3. 右卡「AI 自动记账」/ 副文案用**真实** `auto_count`（如「本月已自动记 12 笔」）→ `/ledger/auto`。
4. **返回刷新**：从 33/34 返回后重新执行 `_load()`（`ledger_page.dart:37`），使总览与最近账单反映新数据。
5. 副文案的**缺省措辞**：`auto_count` 拉取失败或为 0 时用诚实文案（如「看看 AI 记了什么」「本月还没有自动记账」），**不写死「本月已自动记 42 笔」**。
6. `LedgerRepository` 复用 `API-016` 的 `fetchAutoSummary()`（若 `APP-028` 已添加则直接复用；本任务**不新增**方法）。

### 3.2 Out of Scope

| # | 不做 | 理由 |
|---|---|---|
| 1 | 改动总览卡 / AI 观察卡 / 分类支出 / 最近账单的既有结构与解析口径 | 这些区块已通过假数据整改（`progress-audit` §2.1 #2 / §6.1），改动会把已修的诚实性退回 |
| 2 | 在页内实现记账表单或待确认 UI | 归 `APP-027` / `APP-028`；本页只做入口 |
| 3 | 账目编辑 / 冲正 UI | 现无设计要求落点（`REQ-LEDG-05` 的冲正交互不在本次 12 页范围） |
| 4 | 加预算设置入口 | 无设计诉求；预算面属 `REQ-LEDG-06` 既有任务线 |
| 5 | 双入口的下拉刷新 / 骨架屏改造 | 既有 `_loading` / `_error`（L20-23）已够用；改造属范围蔓延 |
| 6 | 把账本页提为主 Tab | Tab 结构由 `REQ-VIS-*` 与 `app_router.dart` 定死，本任务不动。**〔2026-10-03 IA 修订〕**账本页现可作为「动态」位的默认承载页出现在第 2 位，但仍不是独立主 Tab |

| 右 | AI 自动记账 | 本月已自动记 {auto_count} 笔 | `aiPrimary` 浅底 | `/ledger/auto` |

### 4.2 关键裁决

| # | 裁决 | 理由 |
|---|---|---|
| 1 | 副文案必须是**真实数据驱动的动态结论** | `components.md:295` 明文「副文案体现 AI 动态，不写静态说明」；`pages/31:151` 的「42 笔」是示例值，**不得写死** |
| 2 | 用**同一枚语义色**给图标底色：左 `money`、右 `aiPrimary` | 与既有 `_ModuleGrid` 的记账语义色一致（`life_page.dart:178-179`），避免同域两套色 |
| 3 | 返回后**重载而非局部插入** | 一次 `_load()` 保证总览与最近账单同快照；局部插入会与 `fetchSummary` 的聚合口径分叉 |
| 4 | 数据缺失时**不显示数字** | 延续 `APP-014` 空态先例；副文案降级为不含数字的诚实措辞 |
| 5 | 双入口**不加 AI 渐变描边** | `SKILL.md:44` 红线 1：渐变只属 AI 结论卡。右卡虽涉 AI，但它是**入口卡**不是结论卡，用语义浅底 + 图标即可 |
| 6 | 本任务**不新增 repository 方法** | `fetchAutoSummary()` 由 `APP-028` 引入；重复添加会产生两套同名方法 |

### 4.3 数据流

```text
进入 /ledger
  → _load()（ledger_page.dart:37）
      ├─ fetchSummary()       GET /ledger/summary      → 总览卡 + 分类支出
      ├─ fetchEntries()       GET /ledger/entries      → 最近账单
      └─ fetchAutoSummary()   GET /ledger/auto-summary → 双入口右卡副文案
点击「手动记一笔」→ push /ledger/add
  33 页保存成功 → pop(true)
  → 本页 await 结果后再次 _load()                     # 数字立即一致
点击「AI 自动记账」→ push /ledger/auto
  34 页确认 / 忽略可能改变账目 → pop(true) → _load()
```
