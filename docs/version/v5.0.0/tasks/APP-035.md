## 3. Scope

### 3.1 In Scope

1. `album_page.dart`：照 B14 的 10 段。
2. 路由 `/album`（`chromeImmersive`）+ `_tabIndex` 归「生活」Tab。
3. **文案按 D17 / 冲突 17 收敛**：
   - 副题：「只存在这台手机上，不会上传服务器」（保留，成立）。
   - 隐私卡：「相册功能无需联网即可使用，照片不会上传服务器」+「删除的照片进系统『最近删除』，30 天内可恢复」。
   - **不得出现**「不需要联网权限」。
4. 整理建议卡：真实数量 / 体积（`APP-034` 分析结果）+ 入口 → `/album/ai`；**相似连拍若未支持，则卡片只统计已实现类别**（不得把未支持项计入总数）。
5. 分类相簿：真实相簿 + 数量；「截图」相簿带「N 张可清理」（若该分类有建议）。
6. 最近添加：真实缩略图 + 视频时长徽章。
7. 权限态：未授权 → 引导授权；拒权 → 引导去设置；已授权但无照片 → 诚实空态。
8. 分析进行中 → 进度可见且可中断（`APP-034` 的能力）。

### 4.2 关键裁决

| # | 裁决 | 理由 |
|---|---|---|
| 1 | **「不需要联网权限」不得落地**，改为「相册功能无需联网即可使用」（冲突 17） | 朝夕 App 整体必须联网（对话 / 记账 / 记忆），Android 清单必然有 `INTERNET`；原表述是**不可验证的承诺**，审核与信任双输。**「不上传服务器」必须保留**（红线 9 不可谈判项） |
| 2 | 整理建议卡的**总数只计已实现类别** | D16：相似连拍未支持；把未支持项计入会造出"能清理 76 张"的假结论 |
| 3 | 删除口径统一为**系统「最近删除」** | D17（不自建回收站）；`pages/37:166` 的「删除的照片会放进『最近删除』」需补"系统"二字以准确 |
| 4 | 相簿封面用**真实缩略图**，禁用原型渐变占位 | `components.md:371` 明文 |
| 5 | 未授权 / 拒权 / 无照片**三态必须有**，且都不留白 | 延续 `APP-014` 空态先例；相册是权限敏感面，空页会被误判为崩溃 |
| 6 | 分析进度**可见且可中断** | `pages/62:144`「清理随时可以停下，停下的部分不会有任何改变」的技术前提（缺口 28） |
| 7 | 页面零网络：不 import `core/network` | D18 守卫覆盖整域（`APP-034` §4.1） |

### 4.3 数据流

```text
进入 /album
  → （权限未决）引导授权 → 拒权 → 引导设置
  → album_repository.loadAlbums()          # 本机相簿 + 数量
  → album_repository.loadRecent(limit)     # 最近添加（分页）
  → album_analysis.run()                   # isolate，进度回调，可中断
       → 建议集合 { 过期截图, 重复保存 }（相似连拍 = 未支持信号，不计入总数）
点击「看看我发现了什么」→ push /album/ai
点击相簿「旅行」→ push /album/detail?album=…
点击照片 → push /album/photo?id=…
点击「批量管理照片」→ push /album/manage
```
