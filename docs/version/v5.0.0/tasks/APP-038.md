## 3. Scope

### 3.1 In Scope

1. `photo_view_page.dart`：照 B19 的 6 段。
2. 路由 `/album/photo`（`chromeImmersive`）+ 参数 `?id=`。
3. 大图（4:3 / 圆角 18）+ ✦ 徽章「我留了这张」（**仅在有真实判定时**）。
4. AI 说明卡：按可判定场景生成文案；chip 行（对比 → `/album/manage`；「就留这张」= 撤销该张的待清理标记）。
5. 照片信息四行：拍摄时间 / 地点（标注「本机识别，不上传」）/ 相簿（标注「本机归类」）/ 大小（含像素尺寸）；缺失项**整行不渲染**（不写「未知」）。
6. 固定底部操作栏：收藏 / 移到相簿 / 删除；**常驻**口径行（内置在 `AlbumActionBar`）。
7. 零网络。

### 3.2 Out of Scope

| # | 不做 | 理由 |
|---|---|---|
| 1 | **「连拍 4 张里最清楚的一张」类说明** | D16：清晰度评分不可判；写成结论即假数据 |
| 2 | 照片编辑（旋转 / 裁剪 / 滤镜） | 反范围 #4 |
| 3 | 分享到第三方 / 生成链接 | 会引入出域路径，与仅本机口径冲突 |
| 4 | 手势缩放 / 滑动切换相邻照片 | 无设计要求（`components.md:716-730` 未列） |
| 5 | 自建回收站 | D17 |
| 6 | 视频播放页 | 设计稿只给时长徽章与静态大图；播放器属独立范围 |

## 4. Technical Design Requirements

### 4.1 页面契约（照 `components.md:716-730` B19）

| # | 段 | 组件 | 内容 |
|---|---|---|---|
| 1 | 返回 | `BackLink` | 「‹ 相簿 · {相簿名}」 |
| 2 | 大图 | 图片容器 | 4:3 / 圆角 18；右上 ✦ 渐变徽章「我留了这张」（条件渲染）；**不切深色底** |
| 3 | AI 说明卡 | `AiCard` | `[✦]`「亚丝娜的说明」+ 按可判定场景生成的文案 + chip 行（深色主 chip「对比那 N 张」→ `/album/manage`；ghost + ✓「就留这张」） |
| 4 | 区块标题 | `_SectionTitle` | 「照片信息」+ hint「本机读取」 |
| 5 | 信息行 ×4 | 行组件 | 拍摄时间 / 地点（本机识别，不上传）/ 相簿（本机归类）/ 大小（含像素） |
| 6 | 操作栏 | **`AlbumActionBar`（A36）** | 收藏 / 移到相簿 / 删除（危险色）+ **内置**常驻口径行 |

### 4.2 关键裁决

| # | 裁决 | 理由 |
|---|---|---|
| 1 | **「最清楚的一张」不得作为结论** | D16：清晰度评分无实现；改由**重复保存**判定承载（"同一张图存了 3 次，我留了最早的一张"），这是可验证的 |
| 2 | **✦ 徽章条件渲染**（仅有判定时） | `APP-037` §4.2 裁决 2 的同一条纪律：标记必须来自真实判定 |
| 3 | **「对比那 N 张」的 N 必须真实**；无待清理同组时该 chip 不渲染 | chip 指向 `/album/manage`，若 N 为编造值则用户会看到一个空的分组 |
| 4 | 大图**不切深色底** | `components.md:730` 明文；深色与暖纸白纪律冲突 |
| 5 | 信息缺失行**整行不渲染** | 无元数据时不编造、不写「未知」；与 `APP-037` §4.2 裁决 4 同口径 |
| 6 | 「就留这张」= **撤销该张的待清理标记**（写入推翻记录） | `pages/62:139`「你的推翻我会记住」；不写记录则该交互无后果 |
| 7 | 零网络 | D18 守卫 |

### 4.3 数据流

```text
进入 /album/photo?id=…
  → album_repository.loadAsset(id)             # 本机照片 + 元数据
  → album_analysis.decisionFor(id)             # ✦ 判定（仅重复保存场景）+ 同组待清理张数
  → 渲染 6 段
「对比那 N 张」→ push /album/manage（带同组筛选）
「就留这张」→ album_local_store.rememberOverride(id) → 返回后该张不再标为待清理
「删除」→ album_repository.delete([id])        # 系统能力 → 系统「最近删除」
「收藏」/「移到相簿」→ 本地偏好 / 系统相簿操作
```
