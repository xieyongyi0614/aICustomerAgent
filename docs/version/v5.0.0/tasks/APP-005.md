## 2. Background

### 2.1 现状：无路由骨架，且 Tab 形态在 M3 中无法表达

| 事实 | 证据 |
|---|---|
| 原型提供 **9 个可跳转锚点**：`#home` `#chat` `#chatLedger` `#life` `#ledger` `#health` `#memory` `#profile` `#briefing` | `requirements-analysis.md:10`（材料 B 描述） |
| Tab 是「**5 个位置、中间是悬浮球**」的特殊形态，M3 `NavigationBar` **无法表达** | `flutter-architecture.md:73`；`flutter-mapping.md:19`（禁令 5） |
| Tab 栏规格已定稿（高 88 / 模糊底 / 上边线 / 文字 10.5px / 图标 23px / 对话位 flex 0 0 76 / 悬浮球 56px 上浮 24px） | `components.md:88-99`（组件 A9） |
| **两个「球」不是同一个东西**：Orb 是径向渐变 + 呼吸；悬浮球是线性渐变 + ✦、**无动效** | `orb.md:8-20`（§1 辨析表） |
| 进入账本页 / AI 记账页 / 简报页时 **Tab 栏隐藏**；简报页**状态栏文字转白** | `components.md:99` |
| 页面转场 token：`0.38s cubic-bezier(.22,.9,.3,1)` + `opacity 0→1` + `translateY 14px→0` | `tokens.md:228`；`flutter-architecture.md:296` |
| 深链是硬验收项：`APP-018` 简报页要求「深链可达」 | `tasks.md:182` |
| 健康页「从首页 / 生活均可进入」依赖深链 | `traceability.md:61` |
| 屏幕级间距：`top 60 / sides 18 / bottom 118`（底部让开 Tab 栏）；Tab 栏高 88；对话页输入栏 `bottom 88` | `tokens.md:214-220` |
| `go_router` 已选定，原型 `#hash` 可 1:1 映射 | `flutter-architecture.md:20` |

**结论**：仓库中**不存在** Flutter 侧路由层。本任务交付的是**空壳导航**——5 个 Tab 位与 9 条路由可达，页面内容由 `APP-014~025` 填充。

### 2.2 为什么必须做

1. **Tab 自绘是 M3 禁令之一**（`flutter-mapping.md:19`），必须在骨架阶段就把 `NavigationBar` 从代码库里排除掉，否则后续页面会顺手用上。
2. **Tab 隐藏规则是「页面级」的架构约束**，不是页面内的局部判断：账本 / AI 记账 / 简报三页要隐藏 Tab 栏。若在页面内各写各的，会出现「返回后 Tab 栏不还原」这类经典缺陷（`tasks.md:182` 明确要求「返回首页状态栏颜色正确还原」）。
3. **两个球的混淆是已登记的坑**（`orb.md:8-20`）：把 Orb 放进 Tab 栏、或给悬浮球加呼吸动效，都会直接违反设计系统。必须在本任务写清。
4. **深链是 M3 多个页面的验收前置**：`APP-018`（简报）、`APP-024`（健康）、`APP-014`（首页）都要经深链可达。

### 2.3 在 V5.0.0 中的位置

关键路径上：`APP-001 → APP-002 → APP-007 → APP-013 → APP-014`，其中 `APP-005` 是 `APP-014` 的并列依赖（`tasks.md:228-234`）。同时它是 `APP-009`（对话页装配）与全部页面的导航前提。

## 3. Scope

### 3.1 In Scope

1. **`go_router` 声明**：9 条路由与原型锚点 1:1 映射（§4.1.1）。
2. **`AppTabBar`（自绘）**：5 位置 + 中间 56px 悬浮球，规格严格按组件 A9（§4.1.2）。
3. **Tab 栏隐藏规则**：以**路由元数据**表达，而非页面内 `if`（§4.1.3）。
4. **页面转场**：统一接入 `AppMotion.pageTransition`（§4.1.4）。
5. **状态栏样式**：简报页（深色全屏）文字转白，离开后还原（§4.1.5）。
6. **深链参数契约**：路由参数 / query 约定（§4.1.7）。
7. **屏幕级间距接入**：Tab 栏高 88、底部让开 118、对话页输入栏 88（消费 `AppSpacing`）。

## 4. Technical Design Requirements

### 4.1 接口契约

#### 4.1.1 路由表契约（9 锚点 → 路由）

| 原型锚点 | 页面 | 路由路径（逻辑名） | Tab 栏 | 转场 |
|---|---|---|---|---|
| `#home` | 首页 — AI Life Center | 首页 | **显示** | `pageTransition` |
| `#chat` | 对话 | 对话 | **显示** | `pageTransition` |
| `#chatLedger` | AI 记账（对话子流程） | AI 记账 | **隐藏** | `pageTransition` |
| `#life` | 生活 | 生活 | **显示** | `pageTransition` |
| `#ledger` | 账本 | 账本 | **隐藏** | `pageTransition` |
| `#health` | 健康 | 健康 | **显示**（深链可达，见 `traceability.md:61`） | `pageTransition` |
| `#memory` | 记忆 | 记忆 | **显示** | `pageTransition` |
| `#profile` | 我的 | 我的 | **显示** | `pageTransition` |
| `#briefing` | 简报（早间 / 晚间两形态） | 简报 | **隐藏** + **状态栏转白** | `pageTransition` |

**Tab 位与锚点的关系**：5 个 Tab 位分别指向 `#home` / `#life` / `#chat`（悬浮球） / `#memory` / `#profile`；`#ledger` 由 `#life` 进入，`#chatLedger` 由 `#chat` 进入，`#health` 由 `#home` 或 `#life` 进入，`#briefing` 由 `#home` 进入。

来源：`requirements-analysis.md:10`；`tasks.md:110`、`:182`；`traceability.md:41`、`:61`、`:183`。

#### 4.1.2 5 Tab 自绘契约（组件 A9）

| 项 | 规格 | 来源 |
|---|---|---|
| Tab 栏高 | `88` | `tokens.md:218`；`components.md:91` |
| 底色 | `rgba(255,255,255,.92)` + `18px` 背景模糊 | `components.md:91` |
| 上边线 | `1px` `line` | `components.md:91` |
| 位置数 | **5**：首页 / 动态（可变槽，默认记账） / 对话（悬浮球） / 生活 / 我的 | `components.md:92`（**〔2026-10-03 IA 修订〕**原为「首页 / 生活 / 对话 / 记忆 / 我的」） |
| Tab 文字 | `10.5px` / `600` | `components.md:93` |
| Tab 图标 | `23px` | `components.md:93` |
| 未选色 / 选中色 | `ink3` / `ink` | `components.md:93` |
| 对话位宽 | `flex 0 0 76` | `components.md:94` |
| **悬浮球** | `56px` 圆、`ai` **线性**渐变底、`top -24` 居中、阴影 `orbBtnShadow`（外圈 6px 与页面底色同色，形成挖空感）、内为**白色 ✦ 四芒星 24px** | `components.md:95-96` |

**硬约束**：
1. **禁止使用 M3 `NavigationBar`**（禁令 5，`flutter-mapping.md:19`）——本组件必须自绘。
2. 图标一律 Lucide 线性 2px，**禁止 Material Icons**（禁令 4）。
3. 悬浮球内的 ✦ 四芒星路径固定（`tokens.md:245-248`），**不得改形**。
4. 颜色一律经 `APP-002` 的 token 取用，**不得硬编码**。

#### 4.1.3 Tab 栏隐藏规则契约

| 触发页面 | 行为 | 返回时 |
|---|---|---|
| `#ledger`（账本页） | Tab 栏**隐藏** | 返回后 Tab 栏**还原**，选中态回到来源 Tab |
| `#chatLedger`（AI 记账页） | Tab 栏**隐藏** | 同上 |
| `#briefing`（简报页） | Tab 栏**隐藏** + **状态栏文字转白** | 返回后 Tab 栏还原 + **状态栏颜色正确还原**（`tasks.md:182` 明确要求） |

**实现契约**：隐藏规则以**路由元数据**（route 上的一个布尔标记）表达，由 `AppTabBar` 的宿主壳层统一消费。**禁止**在各页面内写 `if (isLedgerPage) hideTabBar` 之类的局部判断。

**理由**：隐藏是**导航层**的关注点，不是页面内容；分散判断会导致「返回后不还原」这类缺陷（`tasks.md:182` 已把它列为验收项）。

来源：`components.md:99`；`tasks.md:182`。

#### 4.1.4 页面转场契约

| 项 | 值 | 来源 |
|---|---|---|
| 时长 | `380ms`（0.38s） | `tokens.md:228` |
| 曲线 | `cubic-bezier(.22,.9,.3,1)` | `tokens.md:228` |
| 透明度 | `opacity 0 → 1` | `tokens.md:228` |
| 位移 | `translateY 14px → 0` | `tokens.md:228` |

**硬约束**：转场参数**必须**取自 `AppMotion.pageTransition`（`APP-002` 交付），**禁止**在路由层另写一套时长 / 曲线（否则会出现两套转场真相）。

#### 4.1.5 状态栏样式契约

| 页面 | 状态栏文字 | 依据 |
|---|---|---|
| 全部浅色页面 | 深色文字 | 底色为暖纸白 `canvas` |
| `#briefing`（深色全屏，背景 `deepBrief`） | **白色文字** | `components.md:99`（「简报页状态栏文字转白色」） |

**契约**：状态栏样式与 Tab 隐藏同源——由路由元数据驱动，离开页面时**必须**还原。**禁止**在页面内直接改全局状态栏而不还原。

#### 4.1.6 悬浮球 vs Orb 辨析契约（**必须写清，防止混用**）

| 维度 | **Orb（AI 本体）** | **悬浮对话球（入口按钮）** |
|---|---|---|
| 视觉 | **径向渐变** + 内层旋转高光 | **线性渐变** `ai` + 白色 ✦ 图标 |
| 动效 | 呼吸 + 色相流动 | **无** |
| 尺寸 | 76 / 34 / 22 | **56** |
| 位置 | 首页 Hero、对话头像、健康 Hero、人格卡、简报页 | **底部 Tab 栏中间**（上浮 24px） |
| 用途 | 表达 **AI 状态** | 表达 **「点这里说话」** |
| 归属任务 | `APP-006` | **本任务（`APP-005`）** |

**两条禁令**（`orb.md:20`）：
1. **禁止**把 Orb 放进 Tab 栏；
2. **禁止**给悬浮球加呼吸动效——**它是个按钮，不是生命体**。

来源：`orb.md:8-20`。

#### 4.1.7 深链参数契约

| 项 | 契约 |
|---|---|
| 形态 | 声明式路由 + 路径参数 / query（**不引入自定义 scheme 解析**，原型用 `#hash` 即可 1:1 映射） |
| 会话参数 | 对话页 / AI 记账页可带会话标识，用于恢复历史 |
| 简报形态 | 简报页带**形态参数**（早间 / 晚间），两形态共用布局（`tasks.md:182`） |
| 账本期间 | 账本页可带期间参数（月 / 周 / 自定义），与 `/ledger/summary` 的期间口径一致 |
| 未知路由 | 落到首页（**不得白屏**） |
| 深链来源 | 通知点击（`APP-019`）、页内跳转、外部唤起 |

### 4.2 关键裁决

| # | 裁决 | 理由 |
|---|---|---|
| **D1** | **Tab 栏自绘（`AppTabBar`），全仓禁用 M3 `NavigationBar`** | 设计稿的 Tab 是「5 位置 + 中间悬浮球」形态，M3 `NavigationBar` 无法表达（禁令 5，`flutter-mapping.md:19`） |
| **D2** | **Tab 中间的是「悬浮对话球（按钮）」，不是 Orb** | 两者视觉、动效、尺寸、用途完全不同（`orb.md:8-20`）。把 Orb 放进 Tab 栏会同时违反红线 1（AI 渐变语义）与 Orb 的功耗纪律 |
| **D3** | **悬浮球无任何动效** | 「它是个按钮，不是生命体」（`orb.md:20`）。加呼吸动效会让用户误判 AI 状态 |
| **D4** | **路由声明集中在 `lib/app/router/`，页面不得自建 Navigator** | 装配层职责（`flutter-architecture.md:166`）；分散路由会让深链无法统一维护 |
| **D5** | **Tab 隐藏与状态栏样式用「路由元数据」驱动，禁止页面内局部判断** | 隐藏是导航层关注点；分散判断会导致「返回后不还原」（`tasks.md:182` 已列为验收项） |
| **D6** | **转场统一走 `AppMotion.pageTransition`，不另写参数** | 避免两套转场真相；token 是唯一真源（`tokens.md:228`） |
| **D7** | **不做路由级鉴权守卫** | `API-001` 未交付前加守卫会阻塞全部页面开发；令牌由 `APP-003` 注入，鉴权失败由统一错误模型处理（`APP-003` §4.1.5） |
| **D8** | **9 个锚点与路由 1:1 映射，不合并、不拆分** | 原型锚点是「唯一可交互真源」（`SKILL.md:30`）；拆分（如把 `#chatLedger` 合并进 `#chat`）会让 Tab 隐藏规则无法表达 |
| **D9** | **健康页 Tab 栏保持显示**，即使 `M4` 门控未通过 | 深链可达是 `APP-014` 三宫格空态分支的前提（`traceability.md:61`）；页面内容可空，路由必须在 |
| **D10** | **未知路由落首页，不白屏** | 深链可能来自通知或外部唤起（`APP-019`）；白屏是不可接受的失败模式 |
| **D11** | **不做 Tab 栏滚动隐藏 / 徽标** | 设计稿未定义（`components.md:88-99` 只有固定高与固定 5 位）；自行添加属发明需求 |

### 4.4 依赖与边界

- **允许依赖**：`APP-001` 工程骨架；`APP-002` 的 `AppColors` / `AppRadii` / `AppSpacing` / `AppMotion` / `AppElevation`（经 `context.<x>` 取用）；`go_router` / `lucide_icons`（均在 20 项清单内）。
