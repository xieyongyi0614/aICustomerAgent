## 3. Scope

### 3.1 In Scope

1. `ledger_add_page.dart`：照 B10 的 8 段信息流（返回 → `seg` → 金额区 → 分类宫格 → 表单行 → AI 提示条 → 数字键盘 → 保存）。
2. 路由 `/ledger/add`（`chromeImmersive`）与返回账本页。
3. `ledger_repository.dart` 新增：`fetchCategories()`（`GET /ledger/categories`）、`createEntry(...)`（`POST /ledger/entries`）、`classifyPreview(note)`（`GET /ledger/classify-preview`）。
4. 备注输入的**防抖预览**（≥300ms 无输入后请求），请求失败时**静默隐藏提示条**（不得报错打断录入）。
5. 保存态：进行中禁用按钮（防重复提交）、失败给可重试提示。
6. 幂等：同一次保存用同一 `idempotency_key` 重试（后端 `idempotency_key` 至少 8 位，`capabilities/ledger.py:50`）。

### 3.2 Out of Scope

| # | 不做 | 理由 |
|---|---|---|
| 1 | 语音记账入口 | `pages/33-ledger-add.html` 无语音键；语音在对话链路（`REQ-LEDG-13` 标为"一直开着"的来源说明），不在本页 |
| 2 | 编辑 / 冲正既有账目 | 既有账目修正走 `POST /ledger/entries/{id}/reverse`（`ledger.py:292`），设计稿在 31 页的最近账单里交互，不属 33 页 |
| 3 | 账户管理（新增/编辑账户） | 表单「账户」是选择项（`pages/33:131`），账户 CRUD 无设计要求 |
| 4 | 备注 → 分类的**自动改写** | 预览是提示（`components.md:568`「AI 的存在收敛为一条提示条，不喧宾夺主」）；自动改分类会夺走用户决定权 |
| 5 | 预算 / 目标联动 | 无设计诉求；`ledger/budgets` 的消费面在 31 页之外的独立任务 |
| 6 | 本地草稿持久化 | 见 §4.2 裁决 5：不在本任务引入端侧业务持久化 |

## 4. Technical Design Requirements

### 4.1 页面契约（照 `components.md:555-568` B10）

| # | 段 | 组件 | 真实文案 |
|---|---|---|---|
| 1 | 返回 | `BackLink` | 「‹ 记账」 |
| 2 | 分段 | `LedgerSeg`（A32） | 支出（选中）/ 收入 |
| 3 | 金额区 | `LedgerAmount`（A32） | 标签「金额」；值 `¥ 35.00` + 输入光标 |
| 4 | 分类宫格 | `LedgerKindGrid`（A32） | 餐饮（选中）/ 交通 / 购物 / 娱乐 / 居住 / 医疗 / 旅行 / 其他（8 类，`pages/33-ledger-add.html:120-127`） |
| 5 | 表单行 | `LedgerFormRows`（A32） | 账户（默认「零钱」）/ 时间（默认「今天 HH:mm」）/ 备注（占位「一碗拉面…」） |
| 6 | AI 提示条 | `AiCard` 单行变体 | 「写下备注，我会帮你自动匹配分类，下次同类消费直接记住」（`pages/33:136-139`） |
| 7 | 数字键盘 | `LedgerPad`（A32） | `1–9 / . / 0 / ⌫` |
| 8 | 主按钮 | `LedgerSaveButton`（A32） | 「保存这一笔」（**深色 ink**，`components.md:315`） |

**交互规则**：
- 宫格选中即写入请求体 `category_name` 对应分类；未选时后端走 `normalize` 兜底（`category.py:38-39` 的 `ledger_category_fallback`）。
- `seg` 切「收入」时宫格按 `kind=income` 重新拉取分类。
- 金额以**整数分**提交（`models/ledger.py:69` `amount_minor > 0`）；端上只做显示层格式化。
- `classifyPreview` 命中的分类**高亮**宫格对应项（不改选中态），未命中则仅提示文案。

### 4.2 关键裁决

| # | 裁决 | 理由 |
|---|---|---|
| 1 | 金额以**整数分**上行，端上仅格式化 | 后端 `amount_minor: int` 且 `_validate_amount_minor` 只收整数（`app/services/action/capabilities/ledger.py:30`）；端上浮点会引入精度漂移 |
| 2 | **不做**备注 → 分类的自动改写 | 见 §3.2 #4 |
| 3 | 预览请求**防抖 ≥300ms** 且失败静默 | 逐字请求会打爆后端；提示条报错会打断录入（`components.md:568` 的"不喧宾夺主"） |
| 4 | 保存按钮在请求中被禁用，`idempotency_key` 在页面生命周期内固定 | 防重复提交造成双笔记账；后端幂等键最短 8 位（`capabilities/ledger.py:50`） |
| 5 | **不引入端侧业务持久化**（漂移草稿） | `apps/mobile` 的 drift 层目前运行时零接线（`reviews/progress-audit-2026-09-29.md` §7.6），复用它会引入一个已死通道；本页用页面内状态即可 |
| 6 | 页面内**零网络直连**：全部经 `data/ledger_repository.dart` | `layer_guards_test.dart:87` 禁 presentation 引 dio |

### 4.3 数据流

```text
页面进入
  → repository.fetchCategories()      GET /ledger/categories        # 宫格数据
备注输入（防抖 300ms）
  → repository.classifyPreview(note)  GET /ledger/classify-preview  # 提示条 + 宫格高亮
保存
  → repository.createEntry(amount_minor, category_name?, direction, occurred_at, note, idempotency_key)
      POST /ledger/entries            → {id}
  → Navigator.pop(true)                # 返回账本页
账本页
  → APP-029 的 _load() 重新拉取 summary/entries → 数字更新
```
