# MEM-007 Task Detail — 显式命令通道（Commands）

> 上游：[../tasks.md](../tasks.md) MEM-007 ｜ [../../design.md](../../design.md) §5 ｜ 依赖：MEM-005

## Task 目标

实现 `memory2/commands.py`：识别「记住/忘掉 X」类显式指令，直通生命周期（remember → 立即 Active(salience=1.0)；forget → 全通道清除）；识别失败静默降级为普通候选。

## 背景 / 为什么需要

v1 对显式指令无专用通道：唯一沾边的是 v9 `action_memory_policy_json`（settings L140）中 `remember_fact`/`create_object` 的 deposit 映射，且 v9 整链 `action_enabled=False` 出厂关闭——「用户明确要求记住」实际靠普通抽取碰运气（任务书 §十六要求显式 remember 直接高置信转正）。同时 v1 `_execute_forget`（memory_service L128）是硬删，不可恢复。

## 当前代码涉及位置

| 位置 | 现状 | 本 Task 动作 |
|---|---|---|
| `app/application/post_process.py` L135 `run_memory_extract` | 普通抽取步骤 | 命令识别挂在 ingest 前置（与 MEM-002 同一接线点，Flag 内） |

## 设计方案

1. **识别**：规则词表优先（记住/记一下/别忘了/忘掉/删除记忆…），模糊表述用 turn_analysis 既有意图信号辅助；不新增 LLM 链。输出 `{action: remember|forget, object: str, confidence}`。
2. **remember**：候选 source_kind=explicit_remember → MEM-003 直通转正（salience=1.0、type 由内容规则映射 preference/fact）；同主题既有记忆则 reinforce 而非新建（MEM-005）。
3. **forget**：对 active 记忆按 `same_topic`+向量邻域匹配 object；**仅唯一高匹配（≥阈值）时执行 forget**；多候选/低匹配 → 不删，降级为普通候选 + trace（防误删，tasks.md Risk 项）。
4. **幂等**：同消息重复命令以 (user_id, message_id, action, object_hash) 幂等。
5. **trace**：`memory_command`（命中与否/匹配度/执行结果/降级原因）。

## 数据模型 / 接口变化

- 新接口：`memory2/commands.handle(message_text, turn_analysis_signal) -> CommandResult`。
- 无新表/新列。

## 核心处理流程

```text
用户消息 → post_process 前置识别
 → [remember → 直通候选(MEM-003) → Active(salience=1.0)]
 → [forget → 匹配 active 记忆 → 唯一高匹配→ lifecycle.explicit_forget | 否则降级候选]
 → [未命中 → 普通候选流程（MEM-002/003）]
 → trace
```

## 与现有模块的关系

- 复用 MEM-003 直通与 MEM-005 forget；匹配用 `same_topic`。
- 不改 v1 `_execute_forget`、v9 action_memory_policy、extractor 链。
- chat_pipeline 前台**不做**任何命令执行（识别在后台 post_process，防前台直写记忆——character-runtime.md 不变量 1）。

## 异常与边界情况

- 误识别 forget → 高匹配唯一性门槛兜底，误删率 0 为验收硬指标。
- object 为空/过短 → 拒绝执行，降级候选。
- 目标记忆已 forgotten → 幂等无操作。
- 识别歧义（「别忘了」是叮嘱不是指令）→ 词表上下文窗口判断，不确定即降级。

## 测试要求

- Unit：指令变体集（≥20 种表述）表驱动；匹配唯一性判定。
- Integration：记住→立即召回；忘掉→三通道 0 命中；模糊指令→不删只产候选。
- Idempotency：同消息重放。
- Regression：Flag OFF 时命令按普通对话处理，行为与 v1 一致。

## 验收标准

- 给定「记住我最喜欢西瓜」，当处理，那么立即 Active(salience=1.0) 且 0 LLM。
- 给定「忘掉那件事」且唯一高匹配，那么该记忆 forgotten 且向量/结构/Context 三通道 0 命中。
- 给定模糊/多匹配 forget 指令，那么不删除任何记忆且 trace 记录降级原因。

## Implementation Constraints

- 识别失败必须静默降级（不误删、不报错给用户）；不新增 LLM 链；不做批量遗忘；前台路径零改动。
