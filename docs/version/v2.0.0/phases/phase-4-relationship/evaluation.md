# Phase 4 Evaluation — Long-term Relationship

> Gate 未全过不得申请开启 `v2_relationship_evolved_enabled`。

## 指标与门槛（Eval Gate）

| ID | 指标 | 测法 | 门槛 |
|---|---|---|---|
| E-REL-01 | 真相源统一审计 | 任一关系事实可答「存在哪/为什么存在」：数值归账本、叙事归 Memory、快照为投影 | 100% |
| E-REL-02 | Shared Experience 合规 | 共同经历随真实交互增长、无凭空条目、可注入 Context 且预算内 | 对账一致 100% |
| E-REL-03 | 数值引擎零改动证明 | evolve() 重放输出与 v1 字节级一致（D1/D2/D3/D5） | 字节级一致 |
| E-REL-04 | 叙事里程碑合理 | 只增、白名单、频控、可溯源 Insight | 100% |

## P4 专属场景

- 里程碑达成 → 账本行 + relationship_fact 记忆互溯。
- 冲突解决事件 → 叙事转写；数值 delta 只在账本。
- Pattern 注入消融：有/无 Pattern 的关系段对比（Judge 评相关性）。
