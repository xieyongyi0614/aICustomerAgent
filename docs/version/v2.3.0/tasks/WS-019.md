## 6. Technical Design

### 6.1 验收矩阵

| 维度 | 用例组 |
|---|---|
| **Flag 矩阵** | ① 全 off（V2.2.0 基线）② 总闸+time ③ ②+daily ④ ③+detection ⑤ ④+scene+habit ⑥ 全开（含 llm_assist mock）——每组断言：维护步序列、prompt 世界段/style 段、事件产出集合 |
| **逐字节一致性** | 同一对话脚本 × 冻结时钟：全 off 时 prompt 快照、response 结构、loop_runs 步骤序列与 V2.2.0 基线**逐字节 diff 为空**（复用 V2.2.0 验收的专项测试模式） |
| **全链路场景** | 架构 §7.1~§7.4 四条链路端到端：日常推进 / 天气变冷→主动提醒 / 前台对话简报 / 长离线追赶 |
| **边界不变量** | §9.3 八条逐条断言（写域扫描：模拟路径对 character_state/personality_state/relationship_*/character_goals 零直写；事件唯一 SoT；0 LLM 断言——llm 调用记录数） |
| **迁移与性能** | 0043↔0045 双向；维护步单 tick DB 查询数与耗时预算；前台 snapshot 耗时不劣化（≤150ms 既有预算） |

### 6.2 人工回归清单骨架（regression-checklist.md）

1. 环境准备：Flag 逐组开启顺序、时钟控制方式、调试面板可用性（WS-018）。
2. 节律组：simulated 模式时间推进、天气演化、day/part 标记。
3. 生活组：当日计划生成与推进、位置迁移、用户影响绑定。
4. 事件组：处境检出（含 LLM 辅助）、目标完成桥、escalation 升级、主动提醒全链。
5. 消费组：WorldBrief 入 prompt、场景风格差异、habit 时间命中、记忆沉淀与反思证据。
6. 韧性组：长离线追赶、事件风暴、Flag 逐闸回退。
7. 每项含：前置 / 操作 / 期望 / 观测点（调试端点 + prompt trace + 库断言）。

## 12. Acceptance Criteria

**功能验收**

1. 六组 Flag 矩阵全部按预期（每组断言项独立可见失败原因）。
2. 全 off 对照：prompt 快照 / response 结构 / loop_runs 序列与 V2.2.0 基线 diff 为空。
3. 四条全链路场景通过（§7.1 日常 / §7.2 降温提醒 / §7.3 前台简报 / §7.4 追赶）。

**数据验收**

4. §9.3 八条边界不变量逐条 PASS（写域扫描零违规、事件唯一 SoT、模拟路径 llm 调用记录为 0）。
5. 迁移 0043↔0045 双向通过；性能预算实测达标并留数据。

**接口验收**

6. 全部既有端点（chat/world/debug/state 等）在六组 Flag 下回归通过。

**异常情况**

7. 任一验收失败：缺陷回溯对应 Task 修复，禁止在验收测试内放宽断言；修复后全矩阵重跑。
8. 性能超预算：记录数据并开独立优化项，不带病发布。

## 附：实施记录（Coding 回填）

- **基线快照生成方式**：全 off 对照不依赖静态 golden 文件，而是同一夹具下断言「v23 字段零出现」——`build_context().brief is None`、`collect_facts()` 无 `impacts`/`current_block`/`active_situations`、`render_world_section(brief=None) == render_world_section()`（追加零字节）。与 V2.2.0 golden prompt 套件（`test_prompt_golden.py`）互补：本套件证明 v23 未新增字节，golden 套件锁定既有字节。
- **Flag 矩阵**：6 组（all_off / master_time / plus_daily / plus_detection / plus_scene_habit / all_on）× 4 类断言（维护步执行、brief 在场、计划生成、处境检出）= 24 项参数化用例。
- **边界不变量**：§9.3 八条中 7 条以断言落地（SoT 幂等唯一、写域扫描零违规、0 LLM、种子可复现、跨度上限、风暴上限、StyleContract 硬约束不变）；第 5 条（scene_state 语义零改动）由 V8 既有套件回归覆盖。
- **写域扫描工具**：`scan_forbidden_writes(user)` 经 `world_repository.SessionLocal`（非 `app.core.db.SessionLocal`）取会话，以与 autouse `_offline_repos` 内存库一致——早期直连 `app.core.db.SessionLocal` 会造成真实 SQLite 文件锁，已修正（本 Task 实施中发现并解决）。
- **性能实测数据**：单 tick 维护步耗时以 `logger.info` 留数据（不设硬阈值防慢机误杀）；前台 snapshot ≤150ms 预算由既有套件守护。
- **人工回归执行结论**：`docs/version/v2.3.0/regression-checklist.md` 已交付（7 组 30+ 条，含执行记录表与发布结论栏）；真实模型执行属发布流程，结论待回写。
- **测试**：`tests/v23/test_ws019_acceptance.py`（40 项）；v23 全套件 182 passed / 2 skipped。
