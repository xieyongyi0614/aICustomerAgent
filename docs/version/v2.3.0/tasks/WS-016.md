架构 §5.5/§8.2 的核心影响面：场景影响回复风格与行为选择、时间影响情绪基线与习惯触发（P2/P4 的消费侧闭环）。V2.2 的 StyleContract 四路输入与冲突消解框架已固化，本 Task 以"插入一档"的最小方式扩展，且全部受独立子闸控制、可逐一关闭回到 V2.2 原序。

## 4. Scope

- `app/services/experience/style_assembler.py` + `style_context.py`：场景输入档（`v23_scene_expansion_enabled`）。

## 6. Technical Design

### 6.1 场景档（style_assembler）

```text
优先级链（Flag on）：硬约束 > 情绪 > 关系档位 > 场景 > 人格调制 > 习惯
场景档产出（来自 SCENE_PROFILES[worlds.current_location]）：
  tone_bias：语气倾向提示（软约束级，低于情绪 channel_bias）
  topic_affordances：话题提示（不进 forbidden/_principles）
  expressiveness_cap：表达档上限（cap 只降低既有情绪强度档，不升高；
    与情绪档冲突时取 min(情绪档, cap)——唯一允许的跨档交互，消解规则固化）
Flag off → 场景档不装配，四路原序逐字节一致。
```

### 6.2 情绪基线信号（experience_signals → state_engine）

```text
world_mood_signal(time_ctx, profile, block, weather):
  energy_delta = clamp(profile.energy_bias + block_energy_bias + weather_bias, -1, +1)
    weather_bias：rainy/snowy → -1（宅家安静），sunny → 0
    block_energy_bias：来自当日 active 块（阅读 -1 / 运动 +1 / 工作 0）
    night 时间修正：part=night → 额外 -1（表达欲下降）
  mood_bias：profile.mood_bias（None 居多）
消费点（既有 state_engine 更新函数内，Flag 内）：
  idle_recovery / 情绪衰减计算后将 energy_delta 叠加于恢复/衰减量（有界，不越过既有 clamp）
  mood_bias 作为既有 mood 计算的弱输入（权重常量，仅当非 None）
```

### 6.3 Habit 时间条件

```text
HABIT 触发条件新增三类（资产层）：
  time_of_day: ["evening","night"]      # part_of_day ∈ 集合
  day_type: ["weekend","holiday"]       # 日型判定复用 WS-007 day_type_of
  location_id: "home.living_room"       # worlds.current_location 精确匹配
评估器：v23_habit_time_enabled 开且 TimeContext 可得时判定这三类；
  Flag off → 忽略时间类条件（既有六类条件照常，保证 v22 资产兼容）；
  TimeContext 不可得 → 时间类条件视为不满足（保守不触发）。
```

### 6.4 数据流

```text
worlds.current_location / TimeContext / active 块 / environment.weather（只读）
  ├→ style_context.build_style_context → 场景档 → StyleContract（> 关系，< 人格）
  ├→ state_engine 更新点 → world_mood_signal → energy/mood 弱输入
  └→ habit_trigger 评估 → 时间条件命中
```

## 12. Acceptance Criteria

**功能验收**

1. 咖啡店场景：StyleContract 出现场景档 tone_bias 与话题提示，表达档不超过 cap；深夜卧室：表达档被压低。
2. 情绪档 rich + 场景 cap=subtle → 最终表达档 subtle（min 消解）；情绪档 subtle + cap=rich → subtle（cap 不升档）。
3. state_engine：夜间/雨天 idle 恢复量减少、运动块后恢复量增加，且 energy 永不越出既有值域 clamp。
4. habit：time_of_day=evening 的习惯仅在晚间 part 命中；Flag off 时该条件被忽略、既有条件行为不变。

**数据验收**

5. character_state/emotion_history 写路径与字段零变化（只变计算输入）；personality_state 零写。
6. HABIT 资产 diff 限于新增条件字段（人工审核项在实施记录登记）。

**接口验收**

无新增接口；prompt 的 style 段在 Flag off 时与 V2.2.0 逐字节一致。

**异常情况**

- SceneProfile/TimeContext/计划缺失 → 场景档与信号降级为无操作（不抛错、不阻断回答）。
- habit 时间条件值非法（未知 part）→ 条件视为不满足并 trace。
