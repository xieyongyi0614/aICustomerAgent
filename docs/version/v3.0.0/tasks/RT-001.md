## 2. Background

### 2.1 为什么需要这个 Task

V2.1.0 已把「Run」建成行为单位（`open_run` → 阶段 → `close_run`，唯一写面 `loop_runs`），但 Runtime 对外仍是**一组函数**（`open_foreground_run` / `run_autonomous_cycle` / `run_event_pregate`），不是接口。任何渠道、任何触发源、未来第二个角色实例，都必须先了解这些函数的参数细节与内部阶段名才能接入。

architecture §5 把 V3.0 的契约面定义为 `AgentRuntime.run(input, context) -> RunResult` + 四类契约。若不先冻结这层，RT-006 ~ RT-020 的段实现会各自发明私有数据结构（Observation / Intention / Feedback），Runtime 会退化成「函数拼装」而非内核。

### 2.2 当前架构问题

| # | 问题 | 证据（当前代码） |
|---|---|---|
| P1 | 无统一入口契约 | `application/agent_runtime/__init__.py` 导出 11 个函数，无 `run` 契约 |
| P2 | 阶段间数据无契约类型 | `controller.run_stage_async` 返回裸 `dict`（`entry`） |
| P3 | 错误/降级语义无契约 | 失败写成 `entry.update({"status": "error", ...})`，`recoverable` 只存在于 V2.1 文档 |
| P4 | 事件无契约 | `runtime_traces.events` 是裸 JSON，事件类型无约束 |

### 2.3 在 V3.0 Runtime 中的位置

本任务与任何业务域解耦，只交付「契约面 + 冻结机制」，是后续全部任务的公共依赖：RT-002 产出 `SessionContext`；RT-005 以 `RuntimeEvent` 为载荷；RT-006 实现 `AgentRuntime.run`；RT-007 ~ RT-012 填槽 `RunResult` 的三段产物；RT-019 用 `correlation_id` 串因果链。

## 3. Scope

### 3.1 In Scope

1. 新增 `contracts.py`：`RuntimeInput` / `SessionContext` / `RunResult` / `RuntimeEvent` / `RuntimeFailure` 五个值对象，`AgentRuntime` Protocol，`RunStatus` / `ErrorKind` / `LoopStage` 类型别名，事件类型常量 `EVENT_*` 与 `EVENT_TYPES`。
2. **字段冻结常量**：`RUNTIME_INPUT_FIELDS` / `SESSION_CONTEXT_FIELDS` / `RUN_RESULT_FIELDS` / `RUNTIME_EVENT_FIELDS` / `RUNTIME_FAILURE_FIELDS`（对照 `app/services/action/contracts.py` 的契约冻结先例）。
3. 值对象校验：`RuntimeInput.kind` ∈ 四类触发源；`received_at` 必须时区感知；`payload` 必须 JSON-safe；`SessionContext.session_id` 非空。
4. **唯一降级裁决函数** `terminal_status_for(failure: RuntimeFailure) -> RunStatus`（纯函数：`recoverable=True → "degraded"`，`False → "aborted"`）。
5. 包导出：`application/agent_runtime/__init__.py` 追加契约符号（既有导出零改动）。
6. 测试侧字段注册表 `tests/v30/runtime_support.py`：登记 V3.0 全部 `runtime_*` 设置字段名 → 归属 Task（防止后续任务擅自发明字段名）。

### 3.2 Out of Scope（明确禁止扩张）

- **不实现 `AgentRuntime.run`**（实现归 RT-006）；不实现任何段逻辑。
- 不建 Session 生命周期（RT-002）、事件总线（RT-005）、状态门面（RT-003）、上下文装配（RT-004）。
- **裁决 A1**：architecture §5.5 的 `RuntimeError` 契约以 **`RuntimeFailure`** 命名落库（避免遮蔽 Python 内建 `RuntimeError`）；字段与语义与 architecture 完全对齐。
- **裁决 A2**：本任务**不新增任何设置字段**。每个开关由其归属任务在自己的批次加入（RT-002 加 `runtime_session_tracking_enabled` 等）；RT-001 只交付测试侧注册表。
- **裁决 A3**：`RunResult.intention` / `action_result` / `feedback` 三槽以**开放槽**（`object | None`）冻结，由 RT-008 / RT-010 / RT-012 在同一模块内以 `TypeAlias` 收窄；**不得改名、不得增删这三槽**。
- 不引入 Pydantic 或第三方序列化；`contracts.py` 只用标准库（对齐 `channels/base.py` 的契约层纪律）。
- 零 DB 读写、零表 / 列变更、零迁移。

## 4. Technical Design Requirements

### 4.1 接口契约（`contracts.py`，签名即实现约定）

```python
RunStatus = Literal["done", "aborted", "degraded"]
ErrorKind = Literal["perception", "decision", "planning",
                    "execution", "feedback", "state", "session"]
LoopStage = Literal["observe", "reason", "plan", "act", "reflect", "update"]
DEFAULT_CHARACTER_ID = "asuna"

@dataclass(frozen=True, slots=True)
class RuntimeInput:                      # 归一化输入（architecture §5.2）
    kind: str                            # 复用 models.TRIGGER_TYPES 四类
    source: str                          # channel 名（web/feishu）或域标识（world/schedule/threshold）
    payload: Mapping[str, Any]            # 归一化事实（消息文本 / 事件类型 / 阈值名）
    received_at: datetime                 # 必须 tz-aware
    channel_identity: ChannelIdentity | None = None   # 允许 import app.channels.base
    thread_id: str | None = None

@dataclass(frozen=True, slots=True)
class SessionContext:                    # 会话载体（挂接位由 RT-002 填）
    session_id: str
    character_id: str = DEFAULT_CHARACTER_ID
    channel: str | None = None
    external_user_id: str | None = None
    thread_id: str | None = None
    trigger_type: str = TRIGGER_CHANNEL_MESSAGE
    run_id: str | None = None
    started_at: datetime = field(default_factory=lambda: datetime.now())

@dataclass(frozen=True, slots=True)
class RunResult:                         # 一次循环终态（architecture §5.3）
    run_id: str
    status: RunStatus
    intention: object | None = None       # 开放槽（裁决 A3 → RT-008 收窄）
    action_result: object | None = None   # 开放槽（裁决 A3 → RT-010 收窄）
    feedback: object | None = None        # 开放槽（裁决 A3 → RT-012 收窄）
    trace_ref: str | None = None
    budget_account: Mapping[str, Any] = field(default_factory=dict)

@dataclass(frozen=True, slots=True)
class RuntimeEvent:                      # 进程内事件（architecture §5.4）
    event_type: str
    run_id: str
    session_id: str | None
    occurred_at: datetime
    payload: Mapping[str, Any] = field(default_factory=dict)
    correlation_id: str | None = None

@dataclass(frozen=True, slots=True)
class RuntimeFailure:                    # 错误契约（architecture §5.5，见裁决 A1）
    kind: ErrorKind
    stage: str                           # 出错所在循环段（LoopStage 或既有阶段名）
    run_id: str
    recoverable: bool
    detail: Mapping[str, Any] = field(default_factory=dict)

@runtime_checkable
class AgentRuntime(Protocol):
    async def run(self, input: RuntimeInput, context: SessionContext) -> RunResult: ...

def terminal_status_for(failure: RuntimeFailure) -> RunStatus: ...
```

**事件常量**（architecture §6.1，供 RT-005 / RT-017 复用）：

```python
EVENT_RUN_OPENED = "RunOpened";         EVENT_STAGE_COMPLETED = "StageCompleted"
EVENT_RUN_CLOSED = "RunClosed";         EVENT_STATE_VERSION_BUMPED = "StateVersionBumped"
EVENT_OBSERVATION_RECORDED = "ObservationRecorded"
EVENT_USER_MESSAGE_RECEIVED = "UserMessageReceived"
EVENT_ACTION_EXECUTED = "ActionExecuted"; EVENT_ACTION_COMPLETED = "ActionCompleted"
EVENT_MEMORY_UPDATED = "MemoryUpdated";  EVENT_RELATIONSHIP_UPDATED = "RelationshipUpdated"
EVENT_TYPES: tuple[str, ...] = (...)     # 上列全部
```

**释放面**：允许 `from app.channels.base import ChannelIdentity` 与 `from app.application.agent_runtime.models import TRIGGER_*`；**禁止** import `app.repositories` / `app.services` / `app.chains` / `app.prompts` / `pydantic`。

### 4.2 职责边界

- 契约对象**零业务语义**：不决策、不读 DB、不调 LLM、不写文件、不发请求。
- 契约对象**不落业务表**（architecture 附：边界不变量 2）；`RunResult` 只作为返回值与 Trace 素材。
- **单一裁决位**：`RuntimeFailure.recoverable` 是降级 / 中断的唯一判据；后续 Task 禁止另立判据（如「错误类型白名单」）。
- 终态值集**复用** V2.1 三值（`done` / `aborted` / `degraded`），不新增终态。

### 4.3 数据流

```text
Channel / 触发源
   → RuntimeInput（kind / source / payload / received_at / channel_identity / thread_id）
   → SessionContext（session_id / character_id / channel 身份 / thread_id / 挂接 run_id）
   → AgentRuntime.run（RT-006 实现）
   → RunResult（status + 三产物槽 + trace_ref + budget_account）
   ↗ RuntimeFailure（失败时随 Trace 落库，不入业务表）
   ↗ RuntimeEvent（段级 / 生命周期事件，经 RT-005 总线）
```

### 4.4 生命周期

契约对象是**纯值**：`RuntimeInput` / `SessionContext` 在 Run 开始时创建；`RuntimeEvent` / `RuntimeFailure` 随段执行产生；`RunResult` 在循环结束时返回。全部对象不可变（`frozen=True`），**Run 内不漂移**，无需清理与释放。
