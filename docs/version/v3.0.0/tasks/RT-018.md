## 2. Background

### 2.1 为什么需要这个 Task

`loop_runs` 的设计是「账不是业务状态」：`mark_step` 崩溃安全（崩溃留 `running` 现场可查）。但这意味着**进程崩溃 / 重启会留下永久的 `running` 行**——没有任何回收机制。行动侧已有先例：`action_engine._recover_stale_executing` / `_expire_planned`（在 `run_action_retry_loop` 维护循环中回收过期执行），Run 侧没有对应物。

同时，Debug / Replay / Evaluation 需要的「执行历史投影」分散在 7 张表（`loop_runs` / `runtime_traces` / `decision_records` / `action_records` / `development_changes` / `relationship_events` / `agent_state_snapshots`），没有统一读取面。

### 2.2 当前架构问题

| # | 问题 | 影响 |
|---|---|---|
| L2 | 中间态处理散落 | 崩溃后 `running` Run 永久残留；无孤儿回收 |
| — | 执行历史无投影 | Debug / Replay / Evaluation 需各自写跨表查询 |
| — | 恢复语义未定义 | 重启后是否会重放未完成 Run 不明确 |

### 2.3 在 V3.0 Runtime 中的位置

RT-018 是持久化层的**读与恢复**半边（写半边由 RT-002/RT-006 完成）：RT-019 的 Debug / Replay / Evaluation 取材全部经本任务的投影查询面；维护步获得孤儿回收能力（先例：行动侧 `_recover_stale_executing`）。

## 3. Scope

### 3.1 In Scope

1. **孤儿 Run 回收**（`recovery.py`）：`sweep_orphan_runs(now=None) -> list[str]` —— `status='running'` 且 `started_at` 早于 `now - runtime_orphan_run_timeout_minutes` 的 Run 收敛为 `aborted`，并在 `steps` 追加收尾条目（`{"step": "orphan_sweep", "status": "error", "error": "orphan_timeout"}`），保留既有现场步骤。
2. **维护挂载**：sweep 挂入既有 `life_loop._run_maintenance`（在 `trigger_reconcile` 步骤之后执行）——**不新增 `loop_runs.kind`**（避免 `ck_loop_runs_kind` CHECK 约束迁移），扫掠结果只记日志与 Trace。
3. **执行历史只读投影**（`execution_history.py`）：`history_for_run(run_id)` / `history_for_session(session_id)` / `latest_snapshot_anchor(user_id)`——跨表只读聚合，供 Debug / Replay / Evaluation 取材。
4. **恢复语义**：进程重启**不重放**未完成 Run；「中断恢复」= Session 视角续接下一次 Run（不恢复 Run 内中间态）。
5. **回放锚点**：`agent_state_snapshots`（既有表）作为时点对齐锚点，零新增快照表。
6. **开关**：`runtime_orphan_run_timeout_minutes`（默认 30）、`runtime_orphan_run_sweep_enabled`（默认 `True`）。

### 3.2 Out of Scope（明确禁止扩张）

- **不重放**：不引入任务重放 / 消息重试机制（未完成 Run 不复活）。
- 不新增表 / 列 / 迁移（只消费 RT-002 的 `0052` 两列）；不新增常驻循环 / worker。
- 不做分布式锁 / 多实例 Run 抢占（飞书多实例已有 shard 路由）。
- 不做状态回放**执行**（投影只读查询，不产生副作用）。
- 不改 `action_engine` 的既有回收（`_recover_stale_executing` / `_expire_planned` 保留原样）。
- 不改 Evaluation 规则（V7.5 只读旁路铁律）。

## 4. Technical Design Requirements

### 4.1 接口契约（`recovery.py` + `execution_history.py`）

```python
# recovery.py
def sweep_orphan_runs(now: datetime | None = None,
                      *, timeout_minutes: int | None = None) -> list[str]:
    """running 且超时的 Run → aborted；返回被收敛的 run_id（幂等：重复扫掠返回空）。"""

def pending_orphan_ids(now: datetime | None = None) -> list[str]: ...   # 只读预览
def resume_session_context(session_id: str) -> SessionContext | None: ...

# execution_history.py（全部只读）
@dataclass(frozen=True, slots=True)
class ExecutionHistory:
    run_id: str
    run: Mapping[str, Any]            # loop_runs 行投影
    traces: tuple[Mapping[str, Any], ...]
    decisions: tuple[Mapping[str, Any], ...]
    actions: tuple[Mapping[str, Any], ...]
    state_changes: tuple[Mapping[str, Any], ...]   # development_changes / relationship_events
    snapshot_anchor: Mapping[str, Any] | None      # agent_state_snapshots 锚点

def history_for_run(run_id: str) -> ExecutionHistory | None: ...
def history_for_session(session_id: str, *, limit: int = 50) -> list[ExecutionHistory]: ...
def latest_snapshot_anchor(user_id: str,
                           character_id: str = DEFAULT_CHARACTER_ID) -> Mapping[str, Any] | None: ...
```

### 4.2 恢复语义（「恢复」到底是什么）

| 场景 | 行为 |
|---|---|
| 进程崩溃留下 `running` Run | 超时后扫掠收敛为 `aborted`（现场步骤保留） |
| 进程重启 | **不重放**任何未完成 Run（无自动复活） |
| 会话中断后继续 | 从 Session 视角开启**下一次** Run（RT-002 `resume_session`） |
| Run 内中间态 | **不恢复**（值对象只存在于 Run 生命周期内） |

### 4.3 关键裁决

| # | 裁决 | 理由 |
|---|---|---|
| D1 | 扫掠**幂等**：只收敛 `running` 且超时的 Run；重复扫掠零副作用 | 维护步可能高频触发 |
| D2 | 收敛为 `aborted` 而非删除；`steps` 追加收尾条目 | 台账即真相；现场可查 |
| D3 | **不新增 `loop_runs.kind`**：sweep 挂在既有 `trigger_reconcile` 维护步之后，结果只记日志与 Trace | 新增 kind 需改 `ck_loop_runs_kind` CHECK → 违反零 Schema 变更 |
| D4 | 恢复 = Session 续接下一次 Run，不恢复中间态 | Run 是行为最小单位（architecture §2.2） |
| D5 | 执行历史**只读**：任何查询零 `INSERT/UPDATE/DELETE` | Replay / Evaluation 只读旁路（V7.5 铁律） |
| D6 | 阈值可配（默认 30 分钟，远大于现有单 Run 时长） | 防止误杀长跑 Run（tasks.md R11） |

### 4.4 依赖

- 允许：`loop_run_repository` / `trace_repository` / `decision_repository` / `action_repository` / `agent_state_snapshot_repository` / `relationship_event_repository` / `development_change_repository`（RT-003，只读）、`session`（RT-002）、`contracts`、`app.core.settings`。
- 禁止：任何写仓储调用、`action_engine` 回收逻辑改动、`app.chains` / `app.prompts`、具体渠道实现。
