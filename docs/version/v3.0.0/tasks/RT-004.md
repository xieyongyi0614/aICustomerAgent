## 2. Background

### 2.1 为什么需要这个 Task

当前上下文装配是**散装**的：`chat_pipeline` 步骤 3 调 `world_engine.build_context`，步骤 4 调 `context_builder.build`，步骤 2 经 `agent_state_assembler` 装配快照——三处各自读取、各自缓存、各自降级，没有任何组件回答「这次循环的上下文是什么、有多长、砍掉了什么、哪段降级了」。

architecture §3.1 把 Context Manager 定义为一等组件：四段（用户 / 世界 / 角色 / 记忆）**只读投影、每 Run 重建、Run 内冻结、超预算裁剪**。本任务只做「装配与契约」，不做任何域内算法。

### 2.2 当前架构问题

| # | 问题 | 证据（当前代码） |
|---|---|---|
| 1 | 装配无组件边界 | `chat_pipeline` 内直接调 3 个来源，顺序与降级策略散落 |
| 2 | 无冻结强制 | Run 中途域写入后再次读取会得到不同内容（S2） |
| 3 | 无预算记账 | `context_total_char_budget` 只在既有段内裁剪，无统一「砍了什么」的账 |
| 4 | 降级不可见 | 世界切片失败返回 `None`，无统一降级记录 |

### 2.3 在 V3.0 Runtime 中的位置

Context Build 是生命周期第 2 步（architecture §2.2），位于 Session Start 之后、Observation 之前。RT-004 为 RT-006（循环）提供「一次循环的输入上下文」，为 RT-007（Observe）提供事实来源，为 RT-008（Reason）提供决策输入。

**裁决 D1（签名修正）**：`tasks.md` RT-004 写作 `assemble(session_context, observation)`；本 Detail 修正为 `assemble(session_context, runtime_input=None, ...)`——因为 architecture §2.2 明确 **Context Build 先于 Observation**，且 RT-004 不得依赖 RT-007。Observation 由 RT-007 消费本模块的产物，方向不可反转。

## 3. Scope

### 3.1 In Scope

1. **装配入口**：`assemble(...) -> RuntimeContext`（async；内部对阻塞 DB 调用走 `asyncio.to_thread`）。
2. **四段上下文**（每段一个 frozen 值对象，来源唯一）：用户段 / 记忆段 / 角色段 / 世界段。
3. **冻结语义**：`runtime_context_freeze_enabled=True` 时同一 Run 内 `assemble` 幂等（返回同一对象）；`False` 时逐次重建（保持 V2.6.1 行为）。
4. **超预算裁剪**：沿用 `context_total_char_budget`；只裁可裁段（world → memory），**角色段与用户段（含身份 / 情绪 / 关系投影）不可裁**；裁剪结果记入 `ContextBudget.dropped_segments`。
5. **段级降级**：任一段失败 → 该段为空值 + `ContextDegradation` 记录，**不抛异常**（对齐 world 旁路纪律）。
6. **开关**：`runtime_context_freeze_enabled`（默认 `False`）+ 注册进 `tests/v30/runtime_support.py`。

### 3.2 Out of Scope（明确禁止扩张）

- **不实现检索 / 排序算法**：记忆走 `services.memory2.retriever`（既有），历史窗走 `services.context_builder`（既有）。
- **不重复检索**：`context_builder.build` 已内含记忆召回与洞察装配；记忆段是它的**投影**，禁止二次调用 retriever（见 §4.2 D2）。
- 不做世界推演；不写 `world_*`；不落地任何表；不产生 LLM 调用。
- 不做 prompt 文本拼接（PromptBuilder 归 `prompts/`）与模板选择。
- 不实现 Observation 构建（RT-007）、不做决策（RT-008）。
- 不改 `services/context_builder` / `application/world_engine` / `agent_state_assembler` 的内部实现（只调用）。

## 4. Technical Design Requirements

### 4.1 接口契约（`context.py`）

```python
@dataclass(frozen=True, slots=True)
class UserContext:                 # 用户段（历史窗 / 摘要 / 渠道身份）
    conversation: ConversationState
    channel: str | None
    external_user_id: str | None
    thread_id: str | None

@dataclass(frozen=True, slots=True)
class MemoryContext:               # 记忆段（`context_builder` 既有召回的投影，见 D2）
    memories: tuple[Any, ...]
    insights: tuple[Any, ...]
    shared_experiences: tuple[Any, ...]
    relationship_patterns: tuple[Any, ...]

@dataclass(frozen=True, slots=True)
class CharacterContext:            # 角色段（RT-003 快照投影）
    snapshot: AgentStateSnapshot
    snapshot_version: int
    versions: Mapping[str, StateVersion]

@dataclass(frozen=True, slots=True)
class WorldContext:                # 世界段（world_engine 只读切片；失败降级为 None）
    payload: Mapping[str, Any] | None

@dataclass(frozen=True, slots=True)
class ContextDegradation:
    segment: str                   # "user" | "memory" | "character" | "world"
    error: str                     # 异常类名（不含敏感信息）
    detail: Mapping[str, Any] = field(default_factory=dict)

@dataclass(frozen=True, slots=True)
class ContextBudget:
    total_chars: int
    used_chars: int
    truncated: bool
    dropped_segments: tuple[str, ...]

@dataclass(frozen=True, slots=True)
class RuntimeContext:              # 不可变运行时上下文（不落表）
    session_id: str
    character_id: str
    user: UserContext | None
    memory: MemoryContext | None
    character: CharacterContext | None
    world: WorldContext | None
    budget: ContextBudget
    degradations: tuple[ContextDegradation, ...]
    time_point: datetime
    frozen: bool

SEGMENT_PRIORITY: tuple[str, ...] = ("character", "user", "world", "memory")
PROTECTED_SEGMENTS: frozenset[str] = frozenset({"character", "user"})

async def assemble(
    session_context: SessionContext,
    runtime_input: RuntimeInput | None = None,
    *,
    run=None,
    now: datetime | None = None,
    trace=None,
) -> RuntimeContext: ...

def current(run) -> RuntimeContext | None: ...            # 冻结态读取
def reset(run) -> None: ...
def context_digest(context: RuntimeContext) -> str: ...   # 内容哈希（冻结幂等断言用）
```

### 4.2 段来源映射（**禁止重复检索**）

| 段 | 唯一来源调用 | 归属 |
|---|---|---|
| **用户段** | `await services.context_builder.build(session_id, user_id, current_input, trace=trace)` → `ConversationState`（历史窗 / 摘要）；身份字段取 `SessionContext` | 既有服务，只调用 |
| **记忆段** | **同一 `ConversationState` 的投影**（`memories` / `insights` / `shared_experiences` / `relationship_patterns`） | 零新增检索（D2） |
| **角色段** | `state.snapshot(user_id, character_id, now)` + `state.version(...)`（RT-003） | 复用 |
| **世界段** | `await asyncio.to_thread(world_engine.build_context, user_id, session_id, trace)`；`world_enabled=False` → `None` | 复用既有只读切片 |

**关键裁决**：

| # | 裁决 | 理由 |
|---|---|---|
| D1 | 签名用 `runtime_input` 而非 `observation`（§2.3） | architecture §2.2：Context Build 先于 Observation |
| D2 | 记忆段是 `context_builder` 产物的**投影**，禁止二次调用 `memory2_retriever.retrieve` | 避免重复检索（`_build_sync` 已含召回），防止成本与语义分叉 |
| D3 | `current_input` 取 `runtime_input.payload["text"]`；缺省时用空串并记 `ContextDegradation(segment="user")`，**不抛异常** | 后台 Run（schedule / threshold）无用户文本；降级优于中断 |
| D4 | 裁剪只在段粒度：按 `SEGMENT_PRIORITY` 逆序丢 **world → memory**；`PROTECTED_SEGMENTS` 永不裁 | 落实 architecture「身份 / 场景 / 情绪 / 关系段不裁」（这些字段位于 character / user 段内） |
| D5 | 冻结只缓存装配产物于 `run.data["runtime_context"]`（开关开） | 与 RT-003 的 `run.data["runtime_state"]` 并列、互不覆盖；Run 结束由调用方 `reset` |
| D6 | 阻塞 IO 一律 `asyncio.to_thread`；`context_builder.build` 本身是 async，直接 `await` | backend AGENTS.md：同步阻塞调用不得直接跑在事件循环上 |

### 4.3 数据流

```text
Session Start（RT-002）
   → assemble(session_context, runtime_input, run=run, trace=trace)
        ├── 冻结命中？(开关开 且 run.data 已有) → 直接返回（幂等）
        ├── 用户段 ← context_builder.build（async）
        ├── 角色段 ← state.snapshot / state.version（to_thread）
        ├── 世界段 ← world_engine.build_context（to_thread；失败 → None）
        ├── 记忆段 ← 用户段投影
        ├── 预算核算 → 超预算则按 SEGMENT_PRIORITY 逆序丢段
        └── 段级 try/except → ContextDegradation 收集
   → RuntimeContext（不可变；写回 run.data 若开关开）
Reason / Plan / Act（RT-008 ~ RT-010）只读消费
```

### 4.4 依赖

- 允许依赖：`app.services.context_builder`、`app.application.world_engine`、`app.application.agent_runtime.state`（RT-003）、`contracts`（RT-001）、`app.core.settings`、`app.models.conversation` / `app.models.agent_state`。

## 5. Implementation Plan

1. **创建模块骨架** `app/application/agent_runtime/context.py`：7 个值对象（4 段 + 预算 + 降级 + 主对象）+ `SEGMENT_PRIORITY` / `PROTECTED_SEGMENTS` + `context_digest`。
2. **实现段装配私有函数**：`_build_user_segment`（await context_builder）/ `_build_memory_segment`（纯投影）/ `_build_character_segment`（to_thread → state）/ `_build_world_segment`（to_thread → world_engine，`world_enabled` 门控）；每个函数自带 try/except → `(segment, degradation | None)`。
3. **实现 `assemble`**：冻结命中检查（D5）→ 段装配（顺序固定）→ 预算核算与裁剪（D4）→ 组装 `RuntimeContext` → 开关开时写回 `run.data`。
4. **实现 `current` / `reset`**：与 `agent_state_assembler.activate_run_state` / `reset_run_state` 同风格（读 / 清 `run.data` 键）。
5. **设置与导出**：`core/settings/agent_runtime.py` 加 `runtime_context_freeze_enabled: bool = False`；`tests/v30/runtime_support.py` 登记；`__init__.py` 导出 `assemble` / `RuntimeContext` / `current` / `reset`。
6. **编写测试** `tests/v30/test_runtime_context_manager.py`（§7）。
7. **逐级执行**：Focused → Module → Fast。
