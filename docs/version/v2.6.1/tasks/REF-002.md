# 4. 实现要点

## 4.1 裁决（冻结）

```text
source="plan" 为正式一等来源：
  - 创建：PlanExecutorBridge Flag on 路径
  - 关系：与 autonomy 同格 user_care/weak（succeeded）
  - 额度：计入自治日额度（防止计划步无限刷行动）
  - 历史：conversation/cancel 语义不变
```

## 4.2 映射表完整性规则

对每个 `(action_type, source, status)` 组合：

- 有行 → 按行投递
- 无行 → 不投递（既有纪律，不静默造默认）

**守卫**：可加轻量断言——「`plan` 成功行 ⊇ `autonomy` 成功行」或至少三类常用 type 覆盖，防止再漂移。

## 4.3 额度口径写进文档

在 architecture 明确：

```text
自治日额度计数口径 = source ∈ {autonomy, plan} 且 created_at ≥ 今日零点
```
