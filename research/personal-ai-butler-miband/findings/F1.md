# F1: 小米手环9Pro健康数据接入路径

## Findings

### [1] 小米手环 9 Pro 官方配套 App 是 Mi Fitness（小米运动健康），不是 Zepp/Zepp Life；设备兼容 Android 8.0+ / iOS 12.0+
- quote: "Adapt APP / Mi Fitness ... Compatible with Android phones Android 8.0 and above / Compatible with iOS phones iOS 12.0 and above"
- url: https://www.mi.com/global/product/xiaomi-smart-band-9-pro
- source_type: primary
- published: unknown
- confidence: high

### [2] 小米手环 9 Pro 官方可得健康/运动指标包括：全天心率、血氧、睡眠（含分期/评分）、全天压力、女性健康、呼吸训练、日常活动、150+ 运动模式、独立 GNSS 五星定位
- quote: "All-day heart rate monitoring ... All-day blood oxygen saturation monitoring ... Women's health management ... All-day stress monitoring ... Advanced sleep tracking ... 150+ sports modes ... Independent GNSS five-satellite positioning"
- url: https://www.mi.com/global/product/xiaomi-smart-band-9-pro
- source_type: primary
- published: unknown
- confidence: high

### [3] 小米手环 9 Pro 心率连续监测可配置为 smart 或每 1/10/30 分钟采样；血氧全天跟踪在久坐时采样；睡眠需开启 advanced monitoring
- quote: "Heart rate: If continuous monitoring is enabled, you can adjust the monitoring frequency as needed, setting it to smart monitoring or measuring every 1, 10 or 30 minutes. Blood oxygen: When all-day tracking is on, it will keep track of your SpO₂ when you are sedentary."
- url: https://www.mi.com/global/product/xiaomi-smart-band-9-pro
- source_type: primary
- published: unknown
- confidence: high

### [4] Zepp OS 官方健康数据外送路径是：Device App 读传感器 → Side Service（跑在 Zepp App 内）→ Fetch API POST 到第三方服务器；官方样例名为 post-health-data，并有讨论帖「How To Extract Health Data from Amazfit Smartwatches to a Web Server」
- quote: "For more information on communication relationships, please refer to How To Extract Health Data from Amazfit Smartwatches to a Web Server ... For a complete example ... Post-Health-Data ... Side Service communicates with third-party Service using Fetch API"
- url: https://docs.zepp.com/docs/guides/architecture/arc/
- source_type: primary
- published: unknown
- confidence: high

### [5] Zepp OS 设备清单仅含 Amazfit/Zepp 产品（Balance/T-Rex/GTR/GTS/Bip/Cheetah/Falcon/Active/Band 7 等），不含小米手环 9 Pro；小米手环不属于 Zepp OS 开发者体系
- quote: "This document lists the dev info for all Zepp OS devices. ... Amazfit Balance 3 ... Amazfit Band 7 ..."
- url: https://docs.zepp.com/docs/reference/related-resources/device-list/
- source_type: primary
- published: unknown
- confidence: high

### [6] Zepp OS 设备侧可读健康传感器粒度：HeartRate.getToday 为当日 0 点起分钟级数组（最长 60*24），另有 resting/AFib；Sleep 含 score/deepTime/分期（WAKE/REM/LIGHT/DEEP，默认每 30 分钟更新）；BloodOxygen 可取 lastDay 24h 均值与 getLastFewHour；Stress.getToday 每分钟记录（最长 24*60）并可按小时/近 7 天聚合
- quote: "Get the heart rate measurement data in minutes from 0:00 to the current moment of the day, the longest array is 60*24 ... By default, the system updates the sleep data every 30 minutes ... Returns the average blood sample data for the past 24 hours, with an array length of 24 ... Get the pressure measurements for the whole day, recorded every minute, the return value is an array of variable length, the maximum length of the array is 24 * 60"
- url: https://docs.zepp.com/docs/reference/device-app-api/newAPI/sensor/HeartRate/
- source_type: primary
- published: unknown
- confidence: high

### [7] Zepp OS 健康数据访问走细粒度 permission code（如 data:user.hd.heart_rate / data:user.hd.sleep / data:user.hd.spo2 / data:user.hd.stress / data:user.hd.workout / data:user.health），须在 app.json permissions 声明
- quote: "permission code: `data:user.hd.heart_rate` ... permission code: `data:user.hd.sleep` ... permission code: `data:user.hd.spo2` ... permission code: `data:user.hd.stress`"
- url: https://docs.zepp.com/docs/reference/device-app-api/newAPI/sensor/HeartRate/
- source_type: primary
- published: unknown
- confidence: high

### [8] Zepp OS 运动数据 getSportData（API_LEVEL 3.6，permission data:user.hd.workout）可返回 speed/avg_speed/pace/avg_pace/distance/duration/calories/cadence/altitude/total_up_altitude 等；用户写入口 addHealthData 仅支持 weight+bmi
- quote: "permission code: `data:user.hd.workout` ... speed ... distance ... duration ... calories ... cadence ... altitude ... addHealthData ... weight ... bmi"
- url: https://docs.zepp.com/docs/reference/device-app-api/newAPI/app-access/getSportData/
- source_type: primary
- published: unknown
- confidence: high

### [9] Zepp 开发者 Console（console.zepp.com）定位是「基于华米智能穿戴设备、健康大数据及算法，为合作伙伴提供数据、智能应用、IoT 设备接入等开放能力」的开放平台；个人开发者可注册并提交 Mini Program，但必须提交隐私政策并声明数据权限，审核 1~5 个工作日——这是设备端应用分发通道，不是面向个人开发者的云健康数据 REST API
- quote: "基于华米智能穿戴设备、健康大数据及算法，为合作伙伴提供数据、智能应用、IoT设备接入等开放能力 ... Privacy Statement ... Calling Permissions ... the review time is generally 1~5 working days"
- url: https://docs.zepp.com/docs/distribute/
- source_type: primary
- published: unknown
- confidence: medium

### [10] App 命名与后端归属：Mi Fitness（com.xiaomi.wearable，原 Xiaomi Wear）后端由 Xiaomi 运营，覆盖较新 Mi Band 8/8 Pro/9 系列与小米手表；Zepp Life（com.xiaomi.hm.health，原 Mi Fit）后端 Zepp Health，覆盖至 Mi Band 7 非 Pro；Zepp（com.huami.watch.hmwatchmanager）覆盖 Amazfit 与 Mi Band 7 Pro/8 Pro
- quote: "Mi Fitness / Xiaomi Wear / com.xiaomi.wearable / Xiaomi / Newer Mi Bands (Mi Band 8, 8 Pro), Xiaomi watches ... Zepp Life / Mi Fit / com.xiaomi.hm.health / Zepp Health / Older Mi Bands (up to Mi Band 7 non-Pro)"
- url: https://gadgetbridge.org/basics/pairing/huami-xiaomi-server/
- source_type: community
- published: unknown
- confidence: high

### [11] 社区路径 Gadgetbridge 已收录 Mi Band 9 Pro，但支持等级为 Unknown/Experimental，需先用 Mi Fitness 官方 App 配对并提取 Xiaomi token/auth_key（Xiaomi protobuf 协议），支持由 PR #4363 加入；不适合当合规主路径
- quote: "Mi Band 9 Pro ... Unknown support ... Requires Xiaomi token to pair ... Experimental ... Support added on pull request #4363 ... Xiaomi protobuf device"
- url: https://gadgetbridge.org/gadgets/wearables/xiaomi/
- source_type: community
- published: unknown
- confidence: high

### [12] 新款小米/华米设备 auth_key 必须先经官方 App 服务端配对产生，不能本地生成；提取途径包括 root 读 sqlite、无 root 读 Mi Fitness 日志字段（encryptKey/token/authKey/huamiAuthKey）、huami-token/huafetcher、Xiaomi Cloud Tokens Extractor——属逆向/半逆向邻域，官方无开放 OAuth 发键接口
- quote: "As the authentication keys are stored on vendor servers, there is no way to generate these keys locally at the moment. ... The authentication key is stored on Huami servers or in the original Mi Fit / Mi Fitness / Xiaomi Wear / Zepp app's database."
- url: https://gadgetbridge.org/basics/pairing/huami-xiaomi-server/
- source_type: community
- published: unknown
- confidence: high

### [13] Android 系统健康平台 Health Connect 可被 Gadgetbridge 写入，可同步字段含 Steps/Distance/HR/SpO2/Blood Glucose/HRV/Body & Skin Temperature/Respiratory rate/Resting HR/Sleep Sessions/Weight/VO2 Max/Exercise Sessions（可开 Detailed workout sync 做每秒粒度）；数据默认留在本机、不上传；Android 14+ 内置 AOSP，Android 13 及以下需装 Google Play 专有 Health Connect 应用
- quote: "Health Connect is Android's unified platform for health and fitness data. ... Gadgetbridge can sync the following data types to Health Connect: Steps, Distance, Heart Rate, Blood Oxygen Saturation (SpO₂), Blood Glucose, Heart Rate Variability (HRV), Body / Skin Temperature, Respiratory rate, Resting heart rate, Sleep Sessions, Weight, VO₂ Max, Exercise Sessions ... Enable Detailed workout sync to include per-second data from workouts ... all data stored in Health Connect stays inside the device"
- url: https://gadgetbridge.org/basics/integrations/health-connect/
- source_type: community
- published: unknown
- confidence: high

### [14] Mi Fitness（小米运动健康）自身是否有官方 Health Connect 写入、CSV/云导出、或面向个人开发者的健康数据开放 API——本轮未能从一手文档证实；小米开放平台/开发者站与 developer.android.com Health Connect 文档抓取失败，Bing 中文检索被污染，故「小米官方云健康 API 对个人开发者开放」目前证据不足，倾向于不存在公开自助申请通道
- quote: "You need to enable JavaScript to run this app." (console.zepp.com 首页，无 API 文档正文可引)
- url: https://console.zepp.com/
- source_type: primary
- published: unknown
